# 315. Global Semantic Freeze — bắt đầu

Bây giờ không nên tiếp tục thêm feature.

Ta chuyển sang nhiệm vụ cuối:

## **Global Semantic Freeze**

Tôi sẽ gom tất cả quy tắc thành 12 nhóm:

```text
01 Core semantic model
02 Types
03 Ownership / Move / Copy / Drop
04 Capability / View / Lifetime
05 Control flow / Error
06 Async / Concurrency
07 Memory / Allocation
08 Traits / Generics / Dispatch
09 ABI / FFI / Representation
10 GPU / Comptime / Reflection
11 Module / Package / Build
12 Compiler / Oracle / Tooling
```

Sau đó kiểm tra từng rule theo 5 cột:

```text
Semantic guarantee
Compiler obligation
Optimization freedom
ABI implication
Library responsibility
```

Đặc biệt tôi sẽ tìm **các quy tắc đang có nguy cơ mâu thuẫn**, chứ không chỉ tổng hợp lại.

Những điểm tôi sẽ soi kỹ nhất là:

```text
Copy ↔ Drop
Move ↔ return
view ↔ relocation
view ↔ await
mut_view ↔ concurrency
Send ↔ closure capture
Share ↔ atomic
Drop ↔ panic
Drop ↔ cancellation
FFI ↔ ownership
Box ↔ stable address
repr(C) ↔ optimizer
GPU buffer ↔ async event
comptime ↔ resource lifetime
trait impl ↔ package fingerprint
```

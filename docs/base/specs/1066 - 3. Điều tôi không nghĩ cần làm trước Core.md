Có — **nếu “core” ở đây nghĩa là core compiler + native toolchain tối thiểu để bắt đầu implement Axiom**, thì theo tôi chúng ta đã đủ rộng để bắt đầu xây.

### B. Memory Model

```text
NO hidden ownership runtime
```


Đặc biệt phải trả lời được:

> Khi một giá trị ra khỏi scope, chính xác điều gì xảy ra?

và:

> Compiler được phép tối ưu lifetime đến mức nào?

Đây là một trong những phần có thể ảnh hưởng toàn bộ ABI + optimizer.

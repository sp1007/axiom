## BOOTSTRAP-420 — MACHINE CODE ENCODER, OBJECT FORMAT & NATIVE ARTIFACT EMISSION

### 420.1 — Completion status

Ta khóa tiếp phần còn thiếu của **BOOTSTRAP-420**. Mục tiêu của task này không phải chỉ “ghi vài byte machine code”, mà phải định nghĩa hoàn chỉnh **native artifact pipeline** của Axiom:

```text
Axiom Source
    ↓
AST / Semantic IR
    ↓
Axiom MIR
    ↓
Target Lowering
    ↓
Machine IR
    ↓
Instruction Selection
    ↓
Register Allocation
    ↓
Machine Instructions
    ↓
Machine Code Encoder
    ↓
Sections + Symbols + Relocations
    ↓
Object Writer
    ↓
Linker
    ↓
Native Artifact
 ┌────────┬────────┬────────┬────────┐
 │  EXE   │  ELF   │ Mach-O │  LIB   │
 └────────┴────────┴────────┴────────┘
```

# 420.2 — Architecture invariant

Axiom compiler **không được thiết kế object format gắn cứng với machine encoder**.

Ba lớp phải độc lập:

```text
Target ISA
    │
    └── Machine Encoder
            │
            ├── bytes
            ├── fixups
            └── relocation requirements
                       │
                       ▼
                Object Backend
                       │
              ┌────────┼────────┐
              ▼        ▼        ▼
            ELF     COFF     Mach-O
```

Điều này cho phép:

- x86-64 + ELF
- x86-64 + PE/COFF
- x86-64 + Mach-O
- AArch64 + ELF
- AArch64 + Mach-O
- AArch64 + PE/COFF
- WASM riêng
- các ISA mới sau này

mà không phải viết lại compiler backend.

# 420.3 — Machine instruction representation

Trước encoder, machine instruction tồn tại ở dạng có cấu trúc, **không phải raw bytes**.

```text
MachineInstruction {
    opcode
    operands[]
    flags
    encoding_class
    size_hint
    constraints
}
```

Operand:

```text
MachineOperand =
    Register
  | Immediate
  | Memory
  | Symbol
  | Block
  | StackSlot
```

Memory operand:

```text
MemoryOperand {
    base_register?
    index_register?
    scale
    displacement
    address_size
}
```

Ví dụ khái niệm:

```text
load rax, [rbx + rcx * 4 + 32]
```

được encoder nhận:

```text
opcode = LOAD
dst    = RAX
memory = {
    base  = RBX
    index = RCX
    scale = 4
    disp  = 32
}
```

chứ không nhận sẵn `48 8B ...`.

# 420.4 — Encoder contract

Mọi ISA backend phải cung cấp:

```text
MachineEncoder.encode(
    MachineInstruction
) -> EncodedInstruction
```

Kết quả:

```text
EncodedInstruction {
    bytes[]
    fixups[]
    size
}
```

`Fixup`:

```text
Fixup {
    offset
    width
    kind
    target
    addend
    pc_relative
}
```

Ví dụ:

```text
call foo
```

không được yêu cầu encoder biết địa chỉ cuối cùng của `foo`.

Encoder tạo:

```text
E8 00 00 00 00
   ↑
   fixup → foo
```

Linker sau đó giải quyết relocation.

# 420.6 — Short/long instruction relaxation

Backend phải hỗ trợ instruction relaxation.

Ví dụ branch:

```text
jump label
```

ban đầu có thể encode:

```text
short jump
```

nếu khoảng cách phù hợp.

Nếu không:

```text
short → near → long
```

Compiler/linker phải có khả năng phát hiện và re-encode.

Nguyên tắc:

> **Không hy sinh correctness để giữ encoding ngắn.**

Nhưng khi có thể rút ngắn instruction mà không thay đổi semantics, linker/backend được phép relaxation.

Điều này đặc biệt quan trọng với mục tiêu binary nhỏ của Axiom.

# 420.11 — Relocation abstraction

Object file:

```text

    section
    offset
    type
    symbol
    addend
}
```

Axiom relocation không nên chứa trực tiếp target-format-specific integer nếu chưa qua lowering.

Ví dụ:


```text

```

# 420.12 — Object file abstraction

```text

    symbols[]
    relocations[]
    metadata
}
```

Format:

```text

```

- incremental compilation
- cache

- cross-platform intermediate artifacts

# 420.23 — Dead code elimination

Linker phải hỗ trợ:

```text
--gc-sections
```

tương đương về semantics, nhưng Axiom coi đây là **default optimization capability**, không phải extension bắt buộc.

Graph:

```text
Entry
 ↓
main
 ├── foo
 │    └── bar
 └── baz

unused()
dead()
```

chỉ reachable sections được giữ lại nếu semantics cho phép.

# 420.26 — Address assignment

Linker thực hiện:

```text
symbol address =
    section base
  + symbol offset
```

Sau đó relocation:

```text
patched_value =
    target_address
  + addend
  - relocation_place
```

đối với PC-relative relocation.

Công thức cụ thể phụ thuộc relocation kind.

# 420.27 — Relocation overflow

Nếu relocation không biểu diễn được target address:

```text
RELocationOverflow
```

phải là compiler/linker diagnostic chính thức.

Không được silent truncation.

Ví dụ:

```text
PCREL32
```

không đủ khoảng cách thì linker phải:

1. relax nếu có encoding tương đương;
2. tạo trampoline nếu target/platform cho phép;
3. hoặc báo lỗi.

# 420.32 — Build cache

Do mục tiêu Axiom có cache/precompiled code reuse, object layer phải hỗ trợ content identity:

```text

 + compiler version
 + target
 + options
 + dependencies
      ↓
```

Nếu không có thay đổi semantic:

```text

```

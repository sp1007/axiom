Tiếp tục **LINKER-001 — Axiom Native Linker**.

Đây là mảnh ghép để hoàn thiện chuỗi:

```text
Axiom source
 → Compiler
 → Machine Encoder
 → Object Writer
 → Axiom Linker
 → Native executable
```

Mục tiêu của linker Axiom là **không cần libc/CRT/linker bên ngoài**, nhưng vẫn có thể liên kết với chúng khi chương trình yêu cầu.

---

# 1. Nguyên tắc kiến trúc

Linker không hiểu:

```text
struct
trait
generic
ownership
borrow
async
Option
Result
```

Nó chỉ hiểu:

```text
Object
Section
Symbol
Relocation
Address
Segment
ABI
Entry point
Import/Export
```

Tức là:

```text
Compiler = semantic correctness
Linker   = binary composition
```

Không để hai tầng lẫn nhau.

# 4. Không để ELF trở thành linker IR

Sai:

```text
ELFSection → linker logic
ELFSymbol → linker logic
```

Đúng:

```text

    ↓

    ↓
```

Điều này cực kỳ quan trọng để sau này PE/Mach-O không phải viết lại linker.

# 23. Overflow checking




# 24. Relaxation

Nhưng v1 nên giữ tối thiểu:


# 31. `main` không nhất thiết là OS entry

Đây là distinction rất quan trọng.

```text id="u5r2n8"
main()
```

có thể là Axiom application abstraction.

OS thực sự gọi:

```text id="v7m4q1"
_start
```

Axiom có thể cung cấp startup shim:

```text id="x8k3p6"
_start
    ↓
initialize runtime pieces if required
    ↓
main
    ↓
exit syscall
```

Nhưng freestanding program có thể bỏ shim.

### ALINK-32

### ALINK-33

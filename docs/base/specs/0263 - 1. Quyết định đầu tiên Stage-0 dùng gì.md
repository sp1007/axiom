Tiếp tục với **BOOTSTRAP-005 — AXIOM0 THỰC CHIẾN**.

Từ đây tôi sẽ không mở thêm feature ngôn ngữ nữa. Ta chuyển sang câu hỏi: **nếu ngày mai bắt một AI agent bắt tay xây Axiom, nó phải bắt đầu bằng code nào, dùng công cụ gì, và milestone đầu tiên chính xác đến đâu.**

# 1. Quyết định đầu tiên: Stage-0 dùng gì?

Tôi đề xuất:

```text
Stage-0 compiler
    ↓
C11/C17
    ↓
Axiom compiler
    ↓
Axiom self-hosted
```

Nhưng C chỉ là **bootstrap substrate**, không phải dependency kiến trúc cuối cùng.

Lý do chọn C:

- compiler host rất phổ biến;
- có thể chạy Windows/Linux/macOS;
- dễ build bằng nhiều compiler;
- ABI đơn giản;
- không cần runtime lớn;
- dễ viết lexer/parser/MIR prototype;
- dễ debug bằng debugger hiện có.

Không dùng:

```text
C++
Rust
LLVM IR làm compiler architecture
```

làm nền tảng chính.

# 23. MIR đầu tiên

```text

    let y = 2;
```

# E11.2 — Atomic & Memory-Ordering Litmus Conformance Suite (`tests/conformance/p11/e11_2_atomics`)

Governing specification: `spec/SPEC-31-atomics.md` (Phase 11, Epic E11.2, Task `T409`).

## Suite Inventory

| Test File | Mode | Purpose |
|---|---|---|
| `litmus_mp_acquire_release_and_fences.ax` | `run` (`interp`, `native`, `native-O1`) | `LITMUS-MP` & `LITMUS-MP-FENCE` (`AXS-ATM-061`, `AXS-ATM-062`): Message Passing with `Release`/`Acquire` store/load, Fence-to-Fence (`fence(Release)` + `Relaxed` store / `Relaxed` load + `fence(Acquire)`), Fence-to-Atomic, Atomic-to-Fence, `compiler_fence`, and Release-Sequence RMW (`fetch_add(Relaxed)`) chains. |
| `litmus_sb_seq_cst.ax` | `run` (`interp`, `native`, `native-O1`) | `LITMUS-SB` (`AXS-ATM-063`): Store Buffering with 32-bit and 64-bit `SeqCst` stores/loads (`XCHG` store-buffer drain on x86-64 and global total order $\prec_S$ in the oracle), `Relaxed` stores/loads with `fence(Ordering.SeqCst)` (`MFENCE`), and Dekker mutual exclusion proving `(r0 == 0 && r1 == 0)` is strictly forbidden. |
| `litmus_lb_and_coherence.ax` | `run` (`interp`, `native`, `native-O1`) | `LITMUS-LB` (`AXS-ATM-064`): Load Buffering under `Acquire`/`Release` and `Relaxed` proving no out-of-thin-air (`OOTA`) values (`r0 == 0 && r1 == 0`), plus per-location modification-order coherence (`CoRR`, `CoWR`, `CoWW`, `CoRW`) across deterministic oracle seeds `1..24`. |
| `litmus_rmw_counter_wrapping_and_spinlock.ax` | `run` (`interp`, `native`, `native-O1`) | `LITMUS-RMW` (`AXS-ATM-065`): Lossless concurrent `fetch_add` counter with unique old-value bitmask verification, wrapping two's-complement overflow/underflow across `u8`, `u16`, `u32`, `u64`, `usize`, `i8`, `i16`, `i32`, `i64`, `isize`, bitwise RMW (`fetch_and`, `fetch_or`, `fetch_xor`, `swap`) on `bool` and integers, `is_lock_free<T>()`, and Spinlock mutual exclusion (`compare_exchange_weak` + `spin_loop_hint` + `store(Release)`). |
| `litmus_cas_retry_and_aba.ax` | `run` (`interp`, `native`, `native-O1`) | `LITMUS-CAS-ABA` (`AXS-ATM-066`): Strong `compare_exchange` non-spurious first-attempt success across `8/16/32/64`-bit widths, `compare_exchange_weak` retry loops converging under oracle deterministic spurious failures (`AXS-ATM-054`), unmitigated raw-value ABA behavior (`REQ-CONC-076`, `REQ-ATM-030`), and ABA prevention via packed `(tag: u32, index: u32)` generation counters in `Atomic<u64>` (`REQ-CONC-079`). |
| `litmus_atomic_ptr_tagged_epoch.ax` | `run` (`interp`, `native`, `native-O1`) | Raw-pointer `Atomic<*mut T>` (`AtomicPtr<T>`) conformance (`AXS-ATM-008`, `REQ-CONC-076`..`079`, `REQ-ATM-028`..`030`): pointer-address atomicity without implicit pointee lifetime/ownership or automatic reclamation, safe encapsulated `SafeEpochTreiberStack` with generation tags and explicit retirement epochs, and concurrent `Release`/`Acquire` pointer publication. |
| `qa_signed_cas_const_ptr_and_sb_relaxed.ax` | `run` (`interp`, `native`, `native-O1`) | Boundary conformance for width-exact sub-64-bit atomics in contiguous arrays (no adjacent byte corruption under `SeqCst XCHG`, `LOCK XADD`, bitwise RMW loop, `LOCK CMPXCHG`), signed negative CAS & bitwise RMW across `i8..i64` and `isize` (`AXS-ATM-010`, `AXS-ATM-018`), `Atomic<*const T>` address atomicity (`AXS-ATM-008`), `LITMUS-SB` under `Ordering.Relaxed` (`AXS-ATM-063(2)`), and uniquely owned `Atomic<T>` move and `into_inner()` (`AXS-ATM-012(2)`). |
| `qa_struct_embedded_atomics_and_view_methods.ax` | `run` (`interp`, `native`, `native-O1`) | Boundary conformance for embedding `Atomic<T>` and prelude atomic type aliases (`AtomicBool`, `AtomicU8`, `AtomicU16`, `AtomicU32`, `Atomic<u64>`, `Atomic<*mut u64>`) inside user structs (`AXS-ATM-010`, `AXS-ATM-012`), direct field atomic method dispatch, passing struct fields as `view<AtomicBool>` / `view<AtomicU32>` to helper functions, and ensuring non-atomic neighboring fields remain uncorrupted (`INV-ATM-002`, `INV-CONC-006`). |
| `qa_struct_subword_atomic_ptrs_litmus.ax` | `run` (`interp`, `native`, `native-O1`) | Boundary conformance for struct-embedded sub-64-bit atomics (`AtomicBool`, `AtomicI8`, `AtomicI16`, `AtomicI32`) combined with raw pointer atomics (`Atomic<*mut T>`, `Atomic<*const T>`) under Release/Acquire message passing, release-sequence RMW chains, Store Buffering (SB), negative signed CAS loops, and view-based method dispatch across helper functions (`AXS-ATM-005`, `008`, `010`, `012`, `018`, `023`, `061`, `063`, `INV-ATM-002`, `INV-CONC-006`). |
| `oracle_race_mp_relaxed_ub.ax` | `run` (`interp`, `exit: 125`) | Negative `LITMUS-MP` (`AXS-ATM-061`, `AXS-ATM-052`): Message Passing using `Ordering.Relaxed` without fences fails to synchronize ordinary `payload`, trapped deterministically by the oracle with `AX_UNSAFE_INTERP_UB` (exit code `125`). |
| `oracle_race_mixed_atomic_ordinary_ub.ax` | `run` (`interp`, `exit: 125`) | Negative mixed atomic/ordinary access (`AXS-ATM-005(3)`, `AXS-ATM-052(2)`): Concurrent `Atomic<u64>.store` and non-atomic `*raw = ...` write to the same memory location trapped deterministically with `AX_UNSAFE_INTERP_UB` (exit code `125`). |
| `oracle_ub_misaligned_atomic_ptr.ax` | `run` (`interp`, `exit: 125`) | Negative unaligned atomic pointer access (`AXS-ATM-011(3)`, `AXS-ATM-052(2)`): Loading from an unaligned `*mut Atomic<u64>` address trapped deterministically with `AX_UNSAFE_INTERP_UB` (exit code `125`). |
| `ui_atomic_type_align_ordering_and_mut_view.ax` | `ui` | Negative compile-time diagnostics (`AXS-ATM-060`): `AX_CONC_INVALID_ATOMIC_TYPE` (structs, tuples, `u128`, `fetch_add` on `AtomicBool` and `Atomic<*mut T>`), `AX_CONC_INVALID_ATOMIC_ALIGNMENT` (`@repr(packed)` and `@align(2)` on `AtomicU64`), `AX_CONC_ATOMIC_MUT_VIEW` (`mut_view` of `Atomic<T>` and private `.v` field access), and `AX_CONC_INVALID_ATOMIC_ORDERING` (illegal load/store/fence/CAS orderings and dynamic ordering arguments). |
| `mir_atomic_opt_and_lowering.ax` (`.test`) | `inspect` (`--emit=mir-opt -O1`) | Verifies `MIR_STMT_ATOMIC` lowering and `-O1` optimizer (`const_fold`, `dce`) preservation across all 13 atomic statement kinds (`AXS-ATM-030`..`034`). |

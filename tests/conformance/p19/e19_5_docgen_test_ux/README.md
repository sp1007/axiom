# E19.5 Conformance Suite — Canonical Documentation Generator (`axiomc doc`), Executable Doc-Tests (`axiomc doc --test`), Integrated Test Framework UX 2.0 (`axiomc test`), Differential MIR Oracle (`--interp` / `--diff`), Optimization Pass Replay & Bisection (`--opt-replay` / `--opt-bisect`), and Debug/Trace Verification (`SPEC-104`)

This directory contains the Phase 19 (`E19.5` / `T819`) end-to-end conformance suite for `spec/SPEC-104-docgen-test-framework-ux.md`:
- `e19_5_docgen_test_ux_oracle.test` & `e19_5_docgen_test_ux_oracle.py` — Master conformance oracle validating:
  1. Live bundled execution of `std/meta_effects/mod.ax`, `compiler/query/db/mod.ax`, `compiler/diag/ux2/mod.ax`, `compiler/docgen/mod.ax`, `compiler/driver/doc_cmd/mod.ax`, `compiler/opt/bisect/mod.ax`, `compiler/test_runner/mod.ax`, and `compiler/driver/test_cmd/mod.ax` with `e19_5_docgen_test_ux_probe.ax.in` across `--interp` and native `-O0` compilation (compiled at most once per `<120s` resource budget),
  2. Differential verification (`--interp` vs native `-O1 --verify-each`) of all 4 standalone `.ax` conformance fixtures,
  3. Production binary invariance and stripping audits confirming byte-for-byte identical native codegen with and without `///`/`//!` doc comments and zero leaked `.axmeta`, `.axdb`, `.axmir`, `.axoracle`, or `.axlto` sections or magic bytes in linked production `.exe` images.
- `docgen_html_json_and_intra_links.ax` — `CompilerDB`-backed `///` outer and `//!` inner doc-comment extraction without invoking codegen (`codegen_invoked == false`, `AXS-DOC-001..002`), canonical `=`/`. ` signature rendering with `view<T>`/`mut_view<T>` capability contracts, `@repr(C)`/`@deprecated`/`@since`/`@must_use` attributes, `ContainerContract` and `std.meta_effects` `ApiEffectSummary` badges (`AXS-DOC-003`), intra-doc `[module.Item]` / `[Type.method]` link resolution (`AX_NAME_UNRESOLVED` with `data.context = "doc_link"` and `AX_LEX_COLON_COLON` rejection, `AXS-DOC-004`), and byte-for-byte deterministic offline static HTML (`target/doc/`), `search-index.json`, and `doc-graph.json` (`schema_version = 1`, `AXS-DOC-010..011`, `REQ-TOOL-298`, `INV-DOC-001`).
- `doctest_execution_and_binary_invariance.ax` — `axiomc doc --test` / `axiomc test --doc` executable documentation examples across all fence modes (`run`, `no_run`, `compile_fail(AX_CODE)`, `should_panic(expected = "...")`, `ignore`), `# ` hidden setup line stripping for display vs unprefixing for compilation, exact source-span remapping back to the originating `///`/`//!` comment line/column (`AXS-DOC-012`), and non-semantic doc-comment fingerprint separation (`DocFingerprint` vs `AstFingerprint`/`CodegenFingerprint`) guaranteeing byte-for-byte production binary invariance (`AXS-DOC-005`, `INV-DOC-002`).
- `test_runner_mir_differential_and_bisect.ax` — `axiomc test` compile-time discovery of `test "name" { ... }` and `@test fn` items, deterministic 128-bit `test_id` (`BLAKE3_128("AXIOM-TEST-ID-v1" || module_path || canonical_test_name)`), per-test `target/test-tmp/<test_id_hex>/` isolation, `--jobs <N>` parallel report sorting (`AXS-TST-001..004`), `Verified MIR` reference interpreter (`--interp`) vs native (`-O0`..`-O2`) 6-tuple observable outcome differential comparison (`REQ-TOOL-009`, `INV-TST-001`), and `compiler.opt.bisect` monotonic pass provenance indexing (`--opt-bisect-limit=<N>`), $O(\log_2 M)$ binary-search `--opt-bisect` culprit isolation (`step_id = 6`, `pass = "gvn"`, `4` evaluations over `M = 16` steps), and self-contained `--opt-replay=<manifest>` reproduction (`AXS-TST-020..022`, `REQ-TOOL-179`, `INV-TST-002`).
- `debug_trace_zero_overhead_and_diagnostics.ax` — Build-feature core semantic invariance (`REQ-TOOL-002`), isolated test executable vs production binary separation and zero production runtime requirement for semantic oracle/doc/trace metadata (`REQ-TOOL-003`, `REQ-TOOL-187`), target-independent `SemanticDebugModel` projected to PE/COFF, ELF, Mach-O, and WASM (`REQ-TOOL-007`), mandatory `-O0` `.debug_line` monotonic source-line tables (`REQ-TOOL-010`) vs tiered full DWARF sections (`REQ-TOOL-011`), multi-level `f -> g -> h` logical inline frame reconstruction at a single physical PC (`REQ-TOOL-006`), honest `OptimizedOut` variable reporting with zero `-O2` vs `-O2 -g` codegen drift (`REQ-TOOL-005`), zero-cost disabled tracing (`0` instructions, `0` branches, `0` runtime bytes, `REQ-TOOL-008`), and integrated `axiomc test --audit-debug` & CLI diagnostics (`REQ-TST-112`).

# E18.6 Conformance Suite — Separate Compilation, Multi-Object `LinkIR` Linking, `COMDAT` Deduplication & Section GC (`SPEC-27`)

This directory (`tests/conformance/p18/e18_6_separate_compilation/`) contains the end-to-end Phase 18 (`E18.6` / `T776`) conformance suite certifying `spec/SPEC-27-separate-compilation-linker-v2.md` (`AXS-LNK-001..053`) and `spec/invariants.md` (`INV-LNK-001..003`).

## 1. Conformance Files

| File | Kind | Purpose |
|---|---|---|
| `e18_6_separate_compilation_oracle.test` | `cmd` test | Harness entry point invoking `e18_6_separate_compilation_oracle.py` |
| `e18_6_separate_compilation_oracle.py` | End-to-end oracle | Bundles live `compiler.link.gc` with `e18_6_separate_compilation_probe.ax.in` (`--interp` and native `-O0`), compiles real multi-module `.obj` + `.axmi` + `.lib` + `.dll` workspaces vs whole-workspace builds with `axiomc2`, verifies single-module incremental `.obj` rebuilds & `< 100 ms` no-op budget, checks structured linker diagnostics (`--json` & human), and runs differential checks across all standalone `.ax` tests |
| `e18_6_separate_compilation_probe.ax.in` | Live compiler probe | Directly exercises `compiler.link.gc` (`LinkGcGraph`, `lgc_run_pipeline`, `lgc_emit_gc_sections_report`, `lgc_emit_link_map_report`) across archive extraction, `COMDAT` folding, root-set section GC, forward `.pdata`/`.xdata` unwind sweeping, and negative diagnostic codes |
| `separate_vs_whole_workspace_equivalence.ax` | `run` (`interp`, `native`) | Certifies deterministic topological `.obj`/`.lib`/`.dll` input ordering, cross-object `REL32`/`ADDR64`/`ADDR32NB`/`SECREL`/`SECTION` relocation patching, `Strong`/`Weak`/`Local`/`Import` resolution, and byte-identical equivalence between separate compilation and whole-workspace builds |
| `comdat_generic_vtable_archive_and_section_gc.ax` | `run` (`interp`, `native`) | Certifies per-item section subdivision (`.text$<sym>`, `.rdata$<sym>`, `.data$<sym>`, `.bss$<sym>`, `.pdata$<sym>`, `.xdata$<sym>`), `IMAGE_SCN_LNK_COMDAT` generic/vtable folding (`Any`, `SameSize`, `ExactMatch`, `Largest`, `Associative`), demand-driven `.lib` extraction, root-set mark-sweep section GC (`@entry`, `@export`, `@used`, `@at`, `ModuleInit`, `Reflection`), and `inspect --emit=gc-sections` / `--emit=link-map` |
| `incremental_single_obj_rebuild_and_noop_budget.ax` | `run` (`interp`, `native`) | Certifies the Private-Function Body Firewall for separate `.obj` + `.axmi` compilation (editing a private function in $M_i$ re-typechecks and re-emits only $M_i\text{.obj}$ with `cgu_rebuilt=1` and downstream `.axmi` backdated to `Green`), clean-build equivalence, and `< 100 ms` compiler no-op rebuild |
| `negative_linker_diags_abi_comdat_and_wx.ax` | `run` (`interp`, `native`) | Certifies structured negative linker diagnostics and safety gates: `AX_LINK_UNDEFINED_SYMBOL` (`135`, with `_AX1_` lossless demangling), `AX_LINK_DUPLICATE_SYMBOL` (`136`, strong collision + `NODUPLICATES` / `SAME_SIZE` / `EXACT_MATCH` COMDAT mismatches), `AX_LINK_ABI_MISMATCH` (`153`), `AX_LINK_WX_VIOLATION` (`155`), `AX_LINK_DANGLING_RELOC` (`156`), and `AX_LINK_RELOC_OUT_OF_RANGE` (`137`) |

### Notes (non-blocking; heuristic limits, recommended follow-up for QA/architect)
- N1 `tools/archcheck.py:189-212` blanks preprocessor lines before the INV-LAYER-006 call scan, so
  `#define LOG(x) printf(x)` in a library header plus `LOG("a")` uses escape the rule (probe:
  0 violations). The engineer's test asserts this deliberately. Consider flagging forbidden calls in
  `#define` bodies outside the allowed files.
- N2 `tools/archcheck.py:325,556`: `.inc` files are scanned for includes but not for mutable
  globals / output calls (probe `mir/t.inc` with `static int g;` + `printf` → 0 violations).
- N3 INV-LAYER-007 detects registrations only via `.def` entries and `AX_DIAG(` in C;
  `enum { AX_LEX_FOO = 1 };` in a header is not caught. Acceptable for the registry design of ADR-0005.
- N4 `tools/archcheck_rules.txt:16` comment says output-stream-fn applies "only when the first
  argument is stdout/stderr"; the code (correctly) checks any argument. Stale comment (nit).
- Engineer design decisions 1–7 (report) are consistent with spec/invariants.md; decision 2
  (driver may include objmodel; link may include obj) and 4 (unknown layer dir = violation) are
  worth recording in an ADR at the next architect sitting.

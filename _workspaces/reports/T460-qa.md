### Review of the report's decisions
- **D1 shortest notation** (decimal for 1e-4 <= |x| < 1e16 with `.0` for whole numbers, else `d[.ddd]e[-]N`): AXS-FLT-051 fixes only the
  `.0` rule and the shortest/closest-digit/even-tie property; the thresholds equal Rust's `Debug`. Acceptable and now pinned by vectors.
  Fixed-exp keeps the spec form `d.ddde+XX` (checked: `1.23e+04`). Specials `NaN`/`inf`/`-inf`/`0.0`/`-0.0` match AXS-FLT-050 (`format_wiring.ax`).
  A negative value that rounds to zero in fixed mode keeps its sign (`-0.00`, as C/Rust); the spec is silent, noted for the architect.
- **D2 parse input type**: spec signature `parse_f64(s: Str)`; `Str` is not indexable in the bootstrap language, so `view<[u8]>` (like
  `std.text.fmt.int`), plus `_str(view<String>)` and `unsafe _raw(ptr, len)`. Consistent with the existing int parsers; it is a documented spec
  deviation that needs an architect ADR/spec edit (Follow-up 1). Not a FAIL: the acceptance list names `parse_f32`/`parse_f64 -> Result<..., ParseFloatError>` and the semantics are all tested.
  Grammar checked against AXS-FLT-052: sign, case-insensitive `inf`/`infinity`/`nan`, no whitespace/underscores, `Empty` for "",
  overflow `inf`, underflow +-0.0, exponent digits beyond 1e8 clamped (verified with 20-digit exponents).
- **D3 not in the prelude**: `std.core.prelude` holds only Option/Result/Poll; ADR-0048 loads other std modules on demand. Consequence (verified in the
  snapshot): `let x = f64.NAN;` in a program with no `use std.core.float...` gives `AX_TYPE_UNKNOWN_FIELD`, and the same program with
  `use std.core.float.FpCategory` compiles. The canonical example of AXS-FLT-071 (`use std.math`; `f64.NAN.total_cmp(1.0)`) works only if `std.math`
  (T461) pulls `std.core.float` in. The acceptance criteria do not require prelude loading; recorded as Follow-up 2 for T461/the architect.
- **D4 FpCategory** with `@derive(Copy)` plus hand-written `Clone`/`PartialEq`/`Eq` (spec shows all derived): the compiler limitation in the report's follow-up 1 is
  real (derive on enums fails per the engineer's repro); behaviour is equal. Fine.
- **D5 local panic** (`@intrinsic fn panic(msg: str)` as in `std/fiber/mod.ax`): `clamp_panic.ax` proves exit 101 and stderr `panic: explicit panic`
  natively and in interp. Fine as a stopgap; `std/core/panics.ax` parse failure is already in the engineer's follow-ups.
- **D6 NaN results** are quiet NaNs by `x + x`; checked with `is_nan` and (for operands) bit-exact comparisons in my vectors.
- Spec text of `fract` for `-0.0` is self-contradictory ("`-0.0` for `-0.0` in `self - self.trunc()` or sign-preserving zero"); the implementation returns
  `self - trunc(self)`, i.e. `+0.0` for `-0.0`, which is what the formula gives (my vectors assert it). Noted for the architect (Follow-up 3).
- Spec/rule checks: no new diagnostics; no `BOOTSTRAP-SHORTCUT`; no `bootstrap/axiom0` or compiler change (R7 n/a); no shared-file edit outside `locks:`
  (`format.ax` is locked; `tools/axtest.py`, CMake, `driver/pipeline.c`, `diag/codes.def` untouched); every run test has `modes: interp native` except
  `roundtrip_stress.ax` (see above); the derived operations are not `@intrinsic` (only the five ADR-0049 intrinsics are declared); `std.text.fmt.format`
  is not imported by `compiler/**`, so the re-exports do not reach the self-host bundles (confirmed by grep and by `bundles_current` 34/34).
- Cache hygiene: the python `cmd:` tests read only files of their own directory; no `nocache:` needed. My tests read nothing outside their directory.

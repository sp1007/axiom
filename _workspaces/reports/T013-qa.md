- Boundary Cross-Check: Added `tests/fuzz/qa_empty.ax` in the main tree to verify how the fuzzer handles files in its own directory and refreshed the snapshot.

**Findings:**
- **FAIL**: Broken seed corpus discovery. `tools/fuzz.py` loads `tests/fuzz` first and explicitly skips the rest if it found anything (`if not self.corpus: self._load_corpus(Path("tests/lex")) ...`). This means if the user adds a `.ax` test to `tests/fuzz/` (such as `qa_empty.ax`) or if the fuzzer saves a finding (e.g. `finding_BUG.ax`), all subsequent fuzzer runs completely ignore the actual seed corpus in `lex` and `parse`. This violates the acceptance criteria "Seed corpus from tests/lex + tests/parse".
- **FAIL**: Flawed nondeterminism detection. If the second compiler run (`rc2, out2, err2 = self.run_compiler`) times out, `rc2` becomes `-1`, causing `rc != rc2` to evaluate to true. The fuzzer then falsely reports `NONDETERMINISM`. The timeout check `if elapsed >= 2.0:` is only performed on the first run.
- **FAIL**: The engineer did not run the full gate campaign. The report only cites the 60s `--smoke` test, but the acceptance criteria strictly requires running `--iterations 200000` (campaigns are defined by iteration count, never by wall time per ADR-0005 §3).

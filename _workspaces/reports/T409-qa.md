# T409 QA Gate Report — E11.2: Atomic & Memory-Ordering Litmus Conformance Suite

## Pre-Unblock Cycle (Round 0 Initial Review)

In the initial gate review prior to prerequisite fix T429, QA identified two critical compiler bugs and an acceptance/coverage gap:
1. **Finding 1 (Critical — Native Sub-64-Bit Atomic Codegen Width Overwrite)**: `compiler/driver/pipeline.ax:1859-1864, 4004` overwrote `LirInst.size` to `8u8` for all atomic RMW/CAS instructions, causing adjacent memory corruption and broken negative signed sub-64-bit CAS in native x86-64. Exposed by QA test `qa_signed_cas_const_ptr_and_sb_relaxed.ax`.
2. **Finding 2 (Critical — Typeck Pass 1a Single-Pass Struct Field Resolution Order)**: `compiler/types/typeck.ax:11336-11392, 3369, 3604-3609` resolved struct field types before registering prelude atomic types/aliases, poisoning struct-embedded atomics and subsequent view-based method resolution. Exposed by QA test `qa_struct_embedded_atomics_and_view_methods.ax`.
3. **Finding 3 (Coverage Gap)**: Conformance suite placed atomics exclusively in standalone local variables, omitting struct-embedded atomics, signed negative sub-64-bit CAS, and `Atomic<*const T>`.

Per `T409` Out-of-Scope boundary ("Modifying compiler or std source files"), `T409` was blocked and prerequisite compiler fix task `T429` was created. `T429` resolved both compiler defects and landed at `HEAD 84e792c9`.

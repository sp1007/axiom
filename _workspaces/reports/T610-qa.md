#### Finding 1 — Unsound Bounds-Check Elimination After `Vec<T>.len` Mutation on SROA-Promoted `Vec<T>`
- **Severity**: Critical (Soundness / Safety-Check Removal)
- **Rule / Requirement**: `SPEC-72 §2 AXS-BCE-002`, `AXS-BCE-004` (Rule 1: `Vec<T>.len` stability across mutation), `REQ-OPT-135`, `REQ-OPT-136`, `REQ-OPT-342`
- **Locations**:
  - `compiler/opt/bce/mod.ax:1613-1626` (`bce_collect_length_and_subslice_facts`)
  - `compiler/opt/bce/mod.ax:1365-1378` (`bce_lengths_equal_at`)
  - `compiler/opt/bce/mod.ax:728-746` (`bce_inst_clobbers_len_state`)
- **Expected vs. Actual**:
  - **Expected**: When an owned/by-value mutable `Vec<T>` local (`OPT_LOCAL_SROA`) has `v.len` overwritten (`v.len = 0`) between a dominating `idx < v.len` (or `while i < v.len`) guard and a subsequent `assert(idx < v.len)` / `assert(i < v.len)` check, `bce_lengths_equal_at` MUST return `false` and `opt_bce` MUST retain the check (`checks_eliminated == 0`).
  - **Actual**: `bce_optimize_mir_body` at `OPT_PROFILE_SPEED_O2` eliminates `assert(idx < v.len)` in `bug1a_sroa_vec_len_branch` (`OPT_TERM_ASSERT` count `1 -> 0`, `checks_eliminated = 1`) and eliminates `assert(i < v.len)` in `bug1b_sroa_vec_shrink_in_loop` (`OPT_TERM_ASSERT` count `3 -> 2`, `checks_eliminated = 1`), permitting `unsafe { *(v.ptr + idx) }` to execute after `v.len = 0` without panicking.
- **Root Cause**:
  1. In `bce_collect_length_and_subslice_facts` (`mod.ax:1613-1626`), every SSA `OptValue` with `proj_field == 1u32` of an `OPT_LOCAL_SROA` `Vec<T>` local (`slv`) is registered as a `LengthFact` with `is_readonly_view: true` and `def_inst_idx: 0u32`, even though `slv` is a mutable `Vec<T>` whose `.len` field has multiple SSA versions (`OptPhi` / `OPT_VAL_INST`).
  2. When `v.len` is mutated across a branch (`if c2 { v.len = 0; }`), SSA construction creates two distinct `OptPhi` values `V_len_guard` and `V_len_check` that both have `proj_field == 1u32` and `root_local == slv`.
  3. `bce_lengths_equal_at` (`mod.ax:1370`) sets `check_mem = false` because both facts carry `is_readonly_view == true`. Inside `bce_inst_clobbers_len_state` (`mod.ax:729-740`), the direct local write check at line 729 requires `inst.place.proj_count == 0` (missing field write `v.len = 0` where `proj_count == 1`), and line 740 returns `false` early when `!check_mem && !mut_borrow_taken && !raw_addr_exposed`, never reaching `writes_proj` at line 746. Furthermore, two distinct SROA SSA `OptValueId`s for `proj_field == 1u32` do not represent equal lengths unless `lp_peel_copy(body, len_val_a).v == lp_peel_copy(body, len_val_b).v`!
  - *(Note: existing negative test `neg_vec_len_mutated` in `tests/run/opt_bce/opt_bce_oracle.py:194` only tested `v: mut_view<Vec<i32>>`, which dereferences `(*v).len` via `OPT_INST_LOAD` rather than `OPT_LOCAL_SROA`.)*
- **Minimal Reproducer**:

#### Finding 2 — Unsound `ALIAS_NO_ALIAS` (`CERTAINTY_PROVEN`) Proof in `bce_prove_subrange_disjoint` When Base Slice Local Is Rebound
- **Severity**: Critical (Soundness / Miscompilation via False `NoAlias`)
- **Rule / Requirement**: `SPEC-72 §2 AXS-BCE-005`, `REQ-OPT-141`, `REQ-OPT-142`
- **Locations**:
  - `compiler/opt/bce/mod.ax:1426-1456` (`bce_collect_length_and_subslice_facts`)
  - `compiler/opt/bce/mod.ax:2935-2982` (`bce_extract_place_slice_or_index`)
  - `compiler/opt/bce/mod.ax:3071-3103` (`bce_prove_subrange_disjoint`)
- **Expected vs. Actual**:
  - **Expected**: Half-open sub-slice disjointness `[lo_a..hi_a)` vs. `[lo_b..hi_b)` is only sound when both sub-slices are derived from the **same SSA base slice value** (i.e. an immutable / single-definition unescaped base local, or verified identical SSA base value with no intervening rebind between `def_a`, `def_b`, and the query point). When `mv` is rebound (`mv = buf;`) between `let left = mv[0..2];` and `let right = mv[2..4];`, `bce_prove_subrange_disjoint` MUST NOT return `ALIAS_NO_ALIAS`.
  - **Actual**: `bce_prove_subrange_disjoint` returns `ALIAS_NO_ALIAS` (`result = 0`, `certainty = CERTAINTY_PROVEN`, `relation = REGION_DISJOINT`, `reason = ALIAS_REASON_RANGE_DISJOINT`) even though `left` is `buf[1..3]` and `right` is `buf[2..4]`, which alias at `buf[2]` (`left[1]` == `right[0]`).
- **Root Cause**:
  - `bce_collect_length_and_subslice_facts` (`mod.ax:1426-1434`) checks `single_def` (`alias_count_local_defs == 1 && !mut_borrow_taken && !raw_addr_exposed`) ONLY on `dst_loc` (`left` and `right`), NOT on `rpl.local.v` (`mv`) or `root_loc`.
  - When `mv` has `def_count == 2` (`let mut mv = buf[1..6]; ... mv = buf;`), `bce_resolve_root_local_chain` (`mod.ax:590-614`) stops at `mv` for both `left` and `right`, setting `root_local = mv` on both `SubsliceRangeFact`s (`[0..2)` and `[2..4)`).
  - `bce_prove_subrange_disjoint` (`mod.ax:3071`) sees `root_a == root_b == mv` and `hi_a (2) <= lo_b (2)` and reports `ALIAS_NO_ALIAS` + `CERTAINTY_PROVEN`. (Same issue affects `bce_extract_place_slice_or_index` at `mod.ax:2961-2980` when indexing `mv[0]` vs `mv[1]` across a rebind of `mv`.)
- **Minimal Reproducer**:
  ```axiom
  fn bug2_rebound_subslice_overlap(buf: mut_view<[i32]>) -> i32 {
      if len(buf) >= 6 {
          let mut mv: mut_view<[i32]> = buf[1..6];
          let left = mv[0..2];   // buf[1..3]
          mv = buf;
          let right = mv[2..4];  // buf[2..4] — overlaps `left` at `buf[2]`!
          left[1] = 10;
          right[0] = 20;
          return left[1];        // 20, yet bce_prove_subrange_disjoint(left, right) == ALIAS_NO_ALIAS (Proven)!
      }
      0
  }
  ```

#### Finding 3 — Unsound `loops_query_dependence` Affine IV & Base-Local Proofs Under Mid-Loop IV Mutation and Mutable Slice Rebinding
- **Severity**: Critical (Soundness / Loop Dependence Analysis)
- **Rule / Requirement**: `SPEC-72 §1.5 AXS-LOOP-010`, `REQ-OPT-146`
- **Locations**:
  - `compiler/opt/loops/mod.ax:3174-3278` (`lp_peel_index_local_copy`, `lp_extract_local_affine_iv`)
  - `compiler/opt/loops/mod.ax:3347-3422` (`loops_query_dependence`)
- **Expected vs. Actual**:
  - **Sub-case 3a (Mid-loop IV increment before second access)**:
    - **Expected**: In `while i < 4 { dep[i] = 99; i = i + 1; let after_inc: i32 = dep[i]; ... }`, iteration `k` writes `dep[k]` and reads `dep[k + 1]`, which is overwritten by iteration `k + 1` (`dep[k + 1] = 99`). `loops_query_dependence(write dep[i], read dep[i])` MUST report a loop-carried anti-dependence (`DEP_WAR_ANTI`, `distance = 1`) or conservative `DEP_UNKNOWN` — NEVER `DEP_LOOP_INDEPENDENT` (`distance = 0`).
    - **Actual**: Returns `DEP_LOOP_INDEPENDENT` (`kind = 1`, `is_constant_dist = true`, `distance = 0`, `certainty = CERTAINTY_PROVEN`).
  - **Sub-case 3b (Loop-mutated slice base local)**:
    - **Expected**: In `while i < 2 { let odd = i * 2 + 1; let even = i * 2; mv[odd] = 11; mv = mv[1..9]; mv[even] = 22; i = i + 1; }`, iteration `0` writes `buf[1]` via `mv[1] = 11` and writes `buf[1]` again via `mv[0] = 22` after `mv = mv[1..9]`. `loops_query_dependence` MUST return `DEP_UNKNOWN` (not `DEP_NONE`).
    - **Actual**: Returns `DEP_NONE` (`kind = 0`, `certainty = CERTAINTY_PROVEN`).
- **Root Cause**:
  - **3a**: `MirProjection.index_local` is a MIR local (`_tmp`), and `lp_peel_index_local_copy` (`mod.ax:3174-3207`) walks `OPT_INST_COPY` instructions purely by `MirLocalId` (`_tmp -> _i`) without inspecting the SSA `OptValueId` (`inst.lhs`) read at `pt_a` / `pt_b`. Then `lp_extract_local_affine_iv` (`mod.ax:3263-3275`) maps any index whose `MirLocalId` equals `(*pvp).src_local.v` (`_i`) to `(phi = pv, scale = 1, off = 0)`, conflating `phi_val` (`i_iter` before `i = i + 1`) with `step_val` (`i_iter + 1` after `i = i + 1`).
  - **3b**: `loops_query_dependence` (`mod.ax:3347`) checks `place_a.local.v == place_b.local.v` without checking `!loops_local_written_in_loop(lp, body, info, place_a.local.v)` and `!loops_local_has_indirect_mutation(body, info, place_a.local.v)` when `place_a` dereferences a slice/view local (`proj_count == 2`, `MIR_PROJ_DEREF` + `MIR_PROJ_INDEX`).
- **Minimal Reproducer**:
  ```axiom

      let mut i: usize = 0;
  ```

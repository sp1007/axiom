### Findings
None blocking.

Notes (non-blocking):
1. The acceptance text says "stub exit code 3 is CRASH"; the implementation treats exit 3 as CRASH only with
   the ICE banner. This follows the later architect decision in SPEC-03 AXS-SEM-082 (a program may exit 3;
   Windows `abort()` without banner from the compiler step still fails the test as a build/compile failure).
   Accepted as the binding rule; the stub's ICE case exits 3, so the acceptance test is still present.
2. Report overstatement: "the program's own stderr is never scanned for the banner" holds for native mode
   only. In interp mode (`axiom0 run --interp`), compiler and program share one stderr, so a program that
   prints a line *starting* with `internal compiler error` is reported CRASH
   ([axtest.py:770](tools/axtest.py#L770) via `compile_failure`). Unavoidable with a single process;
   document in README when T016 fixes the banner (e.g. a more specific banner text makes collisions unlikely).
3. In interp mode, `compile_failure` returns CRASH for a crash status before the `r.rc != expected_exit`
   check at line 794, so line 794 is dead code. Harmless.

## 5. SPEC-115 Cross-Check & Boundary Edge Cases

Cross-checked implementation against `spec/SPEC-115-dynamic-components-plugins-hot-reload.md`:

1. **`@component_interface` VTable Lowering & Fingerprinting (`AXS-COMP-003`, `AXS-COMP-005`)**:
   - VTable header is fixed at 32 bytes (`abi_version`, `vtable_size`, 16-byte `InterfaceFingerprint`, 8-byte reserved), plus 8 bytes per method function pointer.
   - `calculate_vtable_size` matches the Stable Axiom ABI specification (`SPEC-114`).
   - `InterfaceFingerprint`, `TargetTripleFingerprint`, and `StateSchemaId` produce deterministic 128-bit digests.
2. **SemVer Caret Matching (`AXS-COMP-011`) & Pre-Release Rejection**:
   - `^2.1.0` matches `>=2.1.0, <3.0.0`; `^0.2.1` matches `>=0.2.1, <0.3.0`; `^0.0.3` matches `==0.0.3`.
   - Pre-release candidates (e.g. `1.2.1-rc.1`) are strictly rejected against stable requirement constraints.
3. **`ComponentId` Nominal Identity & Syntax (`AXS-COMP-002`)**:
   - Validates `<vendor>.<namespace>.<name>` requiring at least 2 dots, non-empty segments, and `[a-zA-Z0-9_-]`.
   - Verified rejection of leading dots, trailing dots, consecutive dots (`..`), single/double segment strings, and illegal characters (`@`, `$`).
4. **`.axcomp` Binary Section Emission & Validation (`AXS-COMP-005`)**:
   - Magic `0x504D4F43` ("COMP"), FormatVersion 1, HeaderSize 128 bytes.
   - Verified rejection on corrupt magic, unsupported format version, undersized header, out-of-bounds component ID offsets, and section buffer truncation.
5. **Cross-Component Boundary Firewall & Allocator Isolation (`AXS-COMP-020`..`025`)**:
   - Raw pointers (`*T`, `*mut T`) rejected across safe interfaces (`AX_COMP_RAW_POINTER_ESCAPE`).
   - Unleased views (`view<T>`, `mut_view<T>`) rejected without an explicit `ComponentLease` contract (`AX_COMP_UNLOAD_ACTIVE_LEASES`).
   - Plain host heap allocations (`Box<T>`, `Vec<T>`, `String`) crossing boundaries rejected (`AX_COMP_CROSS_ALLOCATOR_VIOLATION`), requiring `ComponentBox<T>` or `ComponentHandle<T>`.
   - `ComponentHandle<T>` safely detects stale generation and stale epoch tokens (`AX_COMP_STALE_HANDLE`).
   - Physical unload rejected while `active_leases > 0` (`AX_COMP_UNLOAD_ACTIVE_LEASES`).
   - Host capability grant verified; unauthorized capability requests rejected (`AX_COMP_CAPABILITY_DENIED`).
   - Duplicate `(ComponentId, SemVer)` process registration rejected (`AX_COMP_DUPLICATE_REGISTRATION`).
6. **`@hot_reload_state` Schema ID & Migration Hook Verification (`AXS-COMP-032`, `AXS-COMP-034`)**:
   - Schema hash sensitivity to field reordering and type changes confirmed.
   - Fast-path identity transition verified when schema hashes match.
   - Missing migration hook rejected (`AX_COMP_HOT_RELOAD_SCHEMA_MISMATCH`).
   - Invalid migration hook signature rejected (`AX_COMP_HOT_RELOAD_MIGRATION_FAILED`).
   - Added comprehensive edge-case fixture `tests/run/component_interface/spec115_edge_cases.ax` (+ `.stdout`) and registered in `component_interface_oracle.py`.

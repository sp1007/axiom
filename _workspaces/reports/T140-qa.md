## Layer 1 — Spec Conformance (`SPEC-03`, `AXS-SEM-030`..`AXS-SEM-035`, `ADR-0034`)

- **Bug 1 (`u64`/`usize` `/` and `%` when high bit is set — `AXS-SEM-032`)**:
  - `bootstrap/axiom0/src/lir/{lir.h,lower.c,print.c}` and `compiler/lir/{lir.ax,builder.ax,mod.ax}` add `AX_LIR_INST_UDIV` / `AX_LIR_INST_UREM` (`LIR_INST_UDIV` / `LIR_INST_UREM`), printed as `udiv` / `urem`, and lower `AX_MIR_BIN_DIV` / `AX_MIR_BIN_REM` (`MIR_BIN_DIV` / `MIR_BIN_REM`) on unsigned integer types (`u8`, `u16`, `u32`, `u64`, `usize`) to `UDIV` / `UREM`.
  - `bootstrap/axiom0/src/target/x64/isel/isel.c` and `compiler/target/x64/isel.ax` (`isel_emit_udiv_urem`) implement branchless 64-bit unsigned division and remainder via half-dividend `idiv` for $d < 2^{63}$ and direct unsigned `cmp`/`setcc AE` for $d \ge 2^{63}$, preserving existing x64 MI opcodes and encoding.
  - `std/text/fmt/int.ax` removes the `u64_div_u32` workaround completely; `format_u64_into` and `parse_u64_radix` use native `/` and `%` directly.
- **Bug 2 (`u64`/`usize` checked `*` overflow when product $\ge 2^{64}$ — `AXS-SEM-030`)**:
  - `bootstrap/axiom0/src/target/x64/isel/isel.c` and `compiler/target/x64/isel.ax` (`isel_emit_uoverflow`) compute 64-bit `UMUL_OVERFLOW` via 32-bit limbs (`a = a1*2^32 + a0`, `b = b1*2^32 + b0`), checking `(a1*b1) != 0 || ((a1*b0) >> 32) != 0 || ((a0*b1) >> 32) != 0 || (((a1*b0 & 0xFFFFFFFF) + (a0*b1 & 0xFFFFFFFF) + ((a0*b0) >> 32)) >> 32) != 0`.
- **Bug 3 (`isize`/`usize` shift bit-width — `AXS-SEM-034`)**:
  - `bootstrap/axiom0/src/mir/build/builder.c` and `compiler/mir/builder.ax` (`mb_type_bit_width`) derive the shift bit-width from `ax_type_layout(lhs_ty, ...).size * 8` (`type_layout(...).size * 8`), yielding `64` on 64-bit targets for `isize` and `usize`.
- **Bug 4 (`bootstrap/axiom0/src/interp/interp.c` C UB on `SHR` by `0`)**:
  - `bootstrap/axiom0/src/interp/interp.c` guards signed right-shift when `shift == 0`, avoiding `sval >> 64` UB in C.

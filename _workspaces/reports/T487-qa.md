### Findings

#### F1 (CRITICAL) — `--trust-root` without explicit `--seed` self-seeds from the just-built `c2` and cannot detect a poisoned cached seed
- **Location**: `tools/bootstrap.py:1235-1236` and `tools/bootstrap.py:1709-1758`.
- **Expected**: In `--trust-root` mode (Scope 4; documented in `T487-report.md` §4 as `python tools/build_axiomc.py --out build --trust-root --opt both`), `c2 == B` must be checked against the **pre-existing** cached seed from `compiler-cache/` (and report `TRUST-ROOT SEED: none` if the cache was empty before the run). If `compiler-cache/` holds a poisoned or diverging seed from an earlier seeded gate (either for the previous commit or for the current commit), `--trust-root` must detect `sha256(c2) != sha256(B)` and exit 1.
- **Actual**: `bootstrap.py:1710-1724` calls `run_stage2_and_stage3_for_opt(..., cache_dir=eff_cache_dir)` **before** calling `resolve_seed_compiler(args.seed or "auto", ...)` at line 1730. Inside `run_stage2_and_stage3_for_opt`, line 1236 immediately calls `store_compiler_cache`, writing (or overwriting!) `axiomc2_<opt>_<current_inputs_hash16>.exe` in `eff_cache_dir` with the newly built clean `c2`. Line 1730 then calls `resolve_seed_compiler("auto", eff_cache_dir, ...)`, whose step 1 (lines 712-717) checks exact current-source inputs first and immediately returns the **just-built `c2` itself** as `tr_seed`.
  - On an **empty** cache directory, `--trust-root` prints `TRUST-ROOT SEED: .../axiomc2_O1_<hash>.exe (cache hit (exact inputs ...), sha256=<sha256(c2)>)` and `TRUST-ROOT (O1) OK` by running `c2 -> A -> B` (trivially `c2 == c3 == c4`).
  - When `compiler-cache/` contains a **poisoned seed** (from a prior commit OR from a prior seeded build of the current commit), `store_compiler_cache` either overwrites it or shadows it with clean `c2`, so `--trust-root` exits `0` (`TRUST-ROOT OK`) and completely misses the poisoned seed.
- **Repro**: `test_t487_qa_adversarial.T487QaAdversarial.test_trust_root_auto_seed_does_not_self_seed_and_catches_poisoned_cache` (in `tools/tests/build_axiomc/test_t487_qa_adversarial.py`).
- **Fix**: Resolve the pre-existing `tr_seed` from `eff_cache_dir` **before** `run_stage2_and_stage3_for_opt` writes to `eff_cache_dir` (deferring `store_compiler_cache` until after `verify_trust_root_c2_equals_seeded_b` succeeds, or passing `cache_dir=None` during `run_stage2_and_stage3_for_opt` when `args.trust_root` is set and storing `c2` into `eff_cache_dir` only after trust-root verification passes).

#### F2 (CRITICAL) — Failed `B != C` and `STAGE0-GUARD` checks write valid manifests / cache entries, causing a re-run with `--reuse-existing` to falsely PASS
- **Location**: `tools/bootstrap.py:1012-1015`, `1069-1072`, `1101-1102`, `1621-1650`, `1703-1707`.
- **Expected**: When seeded mode fails `B != C` (non-determinism) or fails `run_stage0_smoke_guard` (Stage-0 smoke `.exe` divergence), no verified Stage-2 binary or manifest may be left behind as reusable, no rejected `B` may be published to `_workspaces/artifacts/compiler-cache/`, and re-running `build_axiomc.py --out build` (`--stage 2 --seed auto --reuse-existing`) without fixing the source must still fail with exit code 1.
- **Actual**:
  1. `run_seeded_for_opt` copies `B` to `axiomc2*.exe` / `axiomc.exe` and writes `.inputs.json` manifests at lines 1012-1015 **before** verifying `B == C` at line 1088. Because `build_axiomc.py` passes `--stage 2 --seed auto --reuse-existing`, on Run 1 `B != C` exits 1, but on Run 2 `reusable_opts` (lines 1621-1649) finds `B` via `_find_reusable_seeded_stage2`, skips the Stage-3 check because `max_stage == 2` (line 1638), sets `all_existing_reusable = True`, skips `run_stage0_smoke_guard`, and **exits `0`** (`REUSED dir_stage2_O1/axiomc2.exe`).
  2. `run_seeded_for_opt` also calls `store_compiler_cache` (line 1102) **before** `run_stage0_smoke_guard` runs (line 1706). When `STAGE0-GUARD` fails on Run 1 (rc=1), the rejected `B` is **already stored in `compiler-cache/`** AND Run 2 with `--reuse-existing` immediately reuses `B` and **exits `0`**.
- **Repro**:
  - `test_t487_qa_adversarial.T487QaAdversarial.test_seeded_b_not_equal_c_does_not_pass_on_rerun_with_reuse_existing`
  - `test_t487_qa_adversarial.T487QaAdversarial.test_stage0_smoke_failure_does_not_poison_cache_or_pass_on_rerun`
- **Fix**: Do not copy `B` to top-level `axiomc2*.exe` / `axiomc.exe`, do not write `.inputs.json` manifests for `B`/`C`, and do not call `store_compiler_cache` until BOTH `B == C` AND `run_stage0_smoke_guard` succeed (and drop any intermediate manifests on failure). In `reusable_opts`, require verified fixed-point + stage0-guard completion before marking a seeded Stage-2 binary reusable.

#### Finding 1 (CRITICAL SOUNDNESS) — Dereferenced loads of indirection-carrying places drop escape, `param_masks`, and address-observability propagation

- **Expected**: `AESCAPE-26` states only that reading a *scalar* payload `*b -> i32` does not escape `b`'s allocation. When a dereferenced place (`*v`, `*(outer_b.0)`, `(*slot).ptr`) yields a value whose **projected result type carries indirection** (`*mut T`, `Box<T>`, `view<T>`, `mut_view<T>`, slice, indirection-carrying struct/closure), escaping/returning/observing that loaded value escapes/observes the underlying pointer/allocation reachable through `op.place.local` (and must propagate `ind_escape` / `val_escape`, `param_masks`, `address_observable`, and `identity_compared`).
- **Actual**: In `esc_propagate_to_operand` (`mod.ax:2525-2530`), whenever `first_d != op.place.proj_count` (any `MIR_PROJ_DEREF`), the `else` arm is an unimplemented stub (`let _keep = first_d;`) that propagates **zero** escape bits. Likewise, `MIR_RVALUE_USE` (`mod.ax:2853-2870`) gates `dst_obs`/`dst_id`/`dst_st` and `param_masks` propagation on `esc_place_first_deref_idx(rv.use_op.place) == rv.use_op.place.proj_count`.
- **Concrete reproducers (empirically confirmed)**:
  1. *Intraprocedural dangling stack pointer*:
     `_1 = box_new<i32>(42); _3 = copy _1.0; _4 = &mut _3; _0 = copy (*_4); drop(_1); return;`
     `escape_build_info` classifies `_1` as `ESCAPE_NO_ESCAPE` (`ESC_NONE`), and `escape_optimize_mir_body` commits `box_stack_promotions == 1` (`_1` backed by local `_promo_slot`), returning `&mut _promo_slot` — a dangling stack pointer after `return`! Add regression tests in `opt_escape_probe.ax.in` / `opt_escape_oracle.py`.

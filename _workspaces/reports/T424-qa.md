### 3. Native evidence (step 4a)

- Every conformance test uses an exact `stdout:` (decisive native comparison); perf tests use `stdout-contains: OK <name> `
  plus `stderr-contains: BENCH <name> ops=` and the runner's interp-vs-native stdout agreement (T139); the benchmarks also check

  `... 32 0 0` -> `... 32 0 1`: `FAIL [interp]`, `FAIL [native]`, `FAIL [native-O1]` all "stdout differs at byte 31"
  (TOTAL 3 PASS 0 FAIL 3). Restored: TOTAL 3 PASS 3. Command:
  `python tools/axtest.py --compiler build/axiomc2.exe --exclude-requires axiom0-internal --no-cache -j 2 --filter conformance/p11/e11_5_executors/cancel_race`.
- Note (not a FAIL): perf stdout is `stdout-contains`, so the size digits in `OK <name> <size>` are only compared interp-vs-native,
  not against a literal. Tightening to an exact `stdout:` would be a small improvement.

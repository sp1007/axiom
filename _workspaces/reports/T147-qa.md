### Notes (not FAIL)
- N1. `inspect --emit=obj` and `build --emit=obj` share the naming code but not the set or order of
  bodies, so the ordinals differ. Examples:
  - `hello.ax`: build `.Lstr.1.100000`, inspect `.Lstr.0.100000`;
  - `fn_literals_plain.ax`: build `2/3/4`, inspect `0/1/2`;
  - inspect has no `.Lpanic.*` at all (`qa_hello_empty.ax`), and the section order differs.
  Each object follows the ADR-0035 section 1 convention for its own emission order, but section 5
  ("inspect must show the same lowering as build, same symbol naming") is not yet met. This is part
  of T148's "inspect == build" scope; see Follow-ups.
- N2. `tests/obj/determinism/check_string_symbols.py`: the docstring claims "every NUL-terminated
  literal is padded to 8 bytes", but the script never checks it. My `qa_check_panic_and_paths.py`
  covers alignment. Fix the docstring or add the check.
- N3. `tests/selfhost/link/qa_pe_local_symbols.ax` is `modes: native` without a comment giving the
  reason. The reason (direct FFI, ADR-0002) is valid; add a comment line in the generator template.
- N4. `data_syms.c` does not check the `malloc` result (`sym_map`). The rest of the file is
  consistent with axiom0 style, which elsewhere uses `ax_xmalloc`; prefer `ax_xmalloc`.

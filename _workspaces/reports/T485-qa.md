### Findings
- **F-1 (FAIL) - compiler/mir/builder.ax:1726-1782 (`mb_item_cache`, inserts at :1758-1767) and its lookups at :1790-1791, :11110-11111:
  symbol-derived keys share tag bits with address-derived keys in the same map, so a lookup result depends on heap
  addresses.** Keys `member | 1` and `(symbol << 3) | 1` both have low bits 001; `member | 2` and `(symbol << 3) | 2`
  both 010 (HirItems are 8-aligned). Whenever an item address equals `8 * symbol` the two key families alias:
  `mb_is_atomic_fn_item(func)` looks up `(func.symbol << 3) | 1`, which hits the entry `m | 1` of a std.sync.atomic impl
  member `m` located at address `8 * func.symbol`; the function is then treated as atomic (no MIR body built). The ranges
  do overlap in practice: mono clones get symbols from `MONO_FIRST_SYM_ID = 0x08000000` (compiler/traits/mono.ax:64),
  i.e. `8 * symbol` >= 0x40000000 = 1 GiB, inside the heap of a 3-5 GB selfhost compile (the PE is linked with
  dll_characteristics 0; a probe `HeapAlloc` returns ~0x540000-0x5C0000, bottom-up); clones are built through
  `mir_build_fn` -> `mir_build_fn_subst` -> `mb_is_atomic_fn_item` (compiler/driver/pipeline.ax:2591). Async poll fns
  carry symbols `func_addr ^ 0x55AA1234` (compiler/mir/async_lower.ax), so `8 * symbol` spans the whole low-GB heap and
  they also reach `mb_count_generic_params_in_hir` (their span is not the 0xFFFFFFFE clone sentinel), where
  `(sym << 3) | 2` can alias a generic-trait-impl member's `m | 2` entry. The old scans compared symbols with symbols
  and addresses with addresses, so HEAD has no such dependence; the existing key schemes of `thir.expr_methods` were
  chosen to keep the families apart (`(sym<<3)|4/|6` vs address tags 1/2/3). No test exercises a collision (it needs a
  specific heap layout), so the byte-identical runs cannot rule it out; it is an address-dependent (non-deterministic
  in principle) misclassification. Expected: symbol keys in tag classes no address key uses, e.g. `(sym << 3) | 5`
  for the atomic family and `(sym << 3) | 6` for the generic-impl family (address tags are 1-4), or a second map;
  costs no new axiom0 symbols. Repro: code inspection (key construction at builder.ax:1758-1767 vs lookups :1790-1791,
  :11111).

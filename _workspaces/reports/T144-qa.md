## Findings

### Fixed During QA (Within `tests/selfhost/`)

1. **`tests/selfhost/interp_opt/gen_interp_opt_tests.py` stale `CASE_EXP_EXIT` after `T145` & 1 MB stack overflow on `@derive(Copy)` fixtures (`qa_interp_opt_diff_comptime_b.ax`)**:
   - **Symptom**: `selfhost/interp_opt/qa_interp_opt_diff_comptime_b.ax` (`[native]` and `[native-O1]`) failed with exit code `307` (`case_idx = 7`, `tests/run/comptime/array_len.ax`) because `T145` (`commit 54a5f87`) updated `tests/run/comptime/*.ax` to return non-zero `// exit:` checksums (`53, 91, 10, 210, 126, 118, 42`), while `gen_interp_opt_tests.py` without `--axiom0` copied `cached_exits` (`0, 0, 0, 0, 0, 0, 0`) from the existing bundle instead of parsing `// exit:` from `src_bytes`. Once `CASE_EXP_EXIT` was updated, `@derive(Copy)` expansion on `table_struct.ax` and `qa_table_struct_str.ax` exceeded the default 1 MB Win64 stack (`0xC00000FD`).
   - **Fix**: Updated `tests/selfhost/interp_opt/gen_interp_opt_tests.py` to parse `^//\s*exit:\s*(-?\d+)` from `src_bytes` whenever `exp_exit is None` and `not is_ui_err` (so `// exit:` directives in fixture headers are authoritative in both generation and `--check` modes, including `10` and `118` for `table_str.ax` and `qa_table_struct_str.ax` which the Axiom selfhost interpreter evaluates accurately), added `// flags: --stack-reserve=16777216` to `native_only` execution bundles (`qa_interp_opt_diff_comptime_b.ax` and `qa_interp_opt_diff_run_b.ax`), and regenerated both bundles. All `19/19` legs in `tests/selfhost/interp_opt/` now pass (`TOTAL 19 PASS 19 FAIL 0`).

2. **`tests/selfhost/kernel/gen_hash_native.py` and `gen_kernel_tests.py` word `check` CLI argument forwarding**:
   - **Symptom**: `gen_hash_native.py` checked only `"--check" in sys.argv[1:]` (ignoring `"check"`) and `gen_kernel_tests.py` called `gen_hash_native.main()` without forwarding `argv`.
   - **Fix**: Updated `gen_hash_native.py` to accept both `"--check"` and `"check"` (and emit `DIFFERS` to `stderr` as well as `stdout`) and updated `gen_kernel_tests.py` to pass `argv=argv` to `gen_hash_native.main`.

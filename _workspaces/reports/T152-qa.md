#### Finding 1 — Missing `!is_closure` guard in Pass 2 re-typechecks closure `HIR_ITEM_FN` bodies and emits duplicate `__ax_fn_<symbol>` items on nested closures
- **Location**: `compiler/types/typeck.ax:7701-7705` (`typeck_pass1b_and_2`, Pass 2) vs `bootstrap/axiom0/src/types/typeck.c:1967-1968`.
- **Expected (`axiom0`)**: In `bootstrap/axiom0/src/types/typeck.c:1967-1968`, Pass 2 skips synthesized closure `HIR_ITEM_FN` items (`symbol.v >= 0x40000000 && symbol.v < 0x50000000`) that `finish_closure_item` appends to the tail of `hir_file.items`:
  ```c
  bool is_closure = (it->fn.symbol.v >= 0x40000000 && it->fn.symbol.v < 0x50000000);
  if (it->kind == AX_HIR_ITEM_FN && it->fn.body && !is_closure) {
      check_item_body(&cx, it, NULL);
  }
  ```
  Each closure body is already typechecked once inside `check_expr` (`HIR_EXPR_CLOSURE`), so nested closures emit exactly one synthesized `__ax_fn_<symbol>` per closure expression and match `axiom0` byte-for-byte.
- **Actual (`axiomc`)**: `compiler/types/typeck.ax:7701-7705` omits the `!is_closure` check:
  ```axiom
  if tk == HIR_ITEM_FN {
      let orig_m = find_orig_impl_member(hir_file, top_it);
      if (orig_m as usize) == 0 {
          check_item_body(mut_view(*cx), top_it, 0 as *const HirItem);
      }
  }
  ```
  Because `finish_closure_item` (`compiler/types/typeck.ax:5778-5789`) appends synthesized closure `HIR_ITEM_FN` items (`(*fn_item).body = b_ptr`, sharing the closure's `HirBlock*`) to the tail of `hir_file.items` while Pass 2 walks `top_it = (*top_it).next`, Pass 2 walks into every appended closure `HIR_ITEM_FN` and re-runs `check_item_body` on its already-typechecked `HirBlock*`. Whenever a closure body contains a nested closure (either zero-capture `|a: i32| -> i32 { a + (|b: i32| b + 1)(2) }` or capturing an outer-closure local `|a: i32| -> i32 { let m: i32 = a + 10; (|b: i32| m + b)(2) }`), `finish_closure_item` runs a second time on the inner closure (`2^d - 1` synthesized functions for nesting depth `d`), allocating extra `next_closure_id` symbols and emitting dead duplicate `__ax_fn_<symbol>` functions into `hir_file.items`, THIR, MIR, LIR, `.obj`, and `.exe`.
- **Repro**:
  1. Minimal repro:
     ```axiom
     fn main() -> i32 {
         let outer = |a: i32| -> i32 {
             a + (|b: i32| b + 1)(2)
         };
         outer(39) - 42
     }
     ```
     `axiom0 build` -> `4096` bytes (`inspect --emit=thir`: `1539` bytes, 2 anonymous `ItemFn`s); `axiomc build` -> `4608` bytes (`inspect --emit=thir`: `1735` bytes, 3 anonymous `ItemFn`s).
  2. End-to-end corpus failure on `tests/run/parity/closures/qa_closures_edges.ax` (`python build-snap-T152/tools/axtest.py --compiler build-snap-T152/build/axiom0.exe -j 1 selfhost/obj_link_driver/axiomc_e2e.test`):

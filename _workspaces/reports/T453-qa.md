### Adversarial tests I added (all PASS interp, native, native-O1, `--no-cache`)
- `qa_divrem_edges.ax`: 32x32 pairwise boundary matrix for udiv128/sdiv128 (0, 1, 2^63±1, 2^64±1, 2^65, MAX, MIN, MIN+1, divisors with hi=1/lo=0, negative multiples); MIN/-1 and /0 skipped (panic tests cover them natively). Row hashes from exact Python.
- `qa_pressure_flags.ax`: 8 live u128 params (spills), flags (`a < b`, signed `c < d`) produced early and consumed after other arithmetic, shift counts derived from the operand's own low limb (CL/RCX conflicts), SAR with variable count, plus a 300-iteration xorshift/rotate/compare loop with loop-carried pairs and a live narrow counter (targets -O1 regalloc/peephole around ADC/SBB/SHLD/SHRD).
- `qa_shift_amount_types.ax`: shifts by 0/1/63/64/65/126/127 with amount types u8, u32, u64, i32, u128, i64, usize on eight edge values (<<, >>, signed >>), and self-derived amounts.
- `qa_calls.ax`: callee mutating a by-reference 16-byte param (`clobber(q, q)` with the same variable twice; caller copy unchanged), nested sret temporaries `two(two(a,b),two(b,a))`, 5 pair params (stack slots), mixed narrow/wide lists, structs with 128-bit fields passed/returned by value, recursion depth 60.
- `qa_memory.ax`: pairs in structs via `view`/`mut_view` parameters, arrays (element swap), `const` u128/i128, match on i128 literal patterns (0, 1, -1, 2^64), enum payloads.
- `qa_panic_fib_overflow.ax`: checked u128 ADD+ADC carry in a loop traps natively with exit 101 and the exact earlier output.
- `qa_panic_i128_signed_loop.ax`: signed 128-bit multiply overflow (2^64 squared) in a loop traps natively with exit 101 after exact output.
- `qa_regen.py`: generator of the first four (exact Python integers).

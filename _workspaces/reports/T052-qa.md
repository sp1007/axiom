- Ran `python tools/axtest.py --compiler build/axiom0.exe --filter conformance`.

### Findings
1. **Partial move does not invalidate whole struct**
   - **File**: `tests/conformance/adversarial/partial_002.ax`
   - **Expected**: `AX_MOVE_USE_AFTER_MOVE` because `user.name` is moved out, invalidating `user`.
   - **Actual**: Compiler accepts the code without error (exit 0).
   - **Repro**:
     ```axiom
     struct Buffer { x: i32 }
     struct User { age: i32, name: Buffer }
     fn consume(u: User) {}
     fn main() {
         let user = User { age: 20, name: Buffer { x: 1 } };
         let name = user.name;
         consume(user);
     }
     ```

2. **Missing last-use analysis for views**
   - **File**: `tests/conformance/stress/e003.ax`
   - **Expected**: Accepted (capability ends after last use `read(v)`).
   - **Actual**: `AX_CAP_CONFLICT_MUT` on `mutate(mut_view(b))`.
   - **Repro**:
     ```axiom
     struct Buffer { x: i32 }
     fn read(v: view<Buffer>) {}
     fn mutate(b: mut_view<Buffer>) {}
     fn main() -> i32 {
         let b = Buffer { x: 1 };
         let v = view(b);
         read(v);
         mutate(mut_view(b));
         return 0;
     }
     ```

### Findings
1. **archcheck_selftest mismatch**: `gatecheck.py` reports `MS-P1 BLOCKED: check archcheck_selftest exited 1`. This is an architect/tooling bug outside the scope of T052.
2. **Incomplete T126 implementation**: After removing `xfail: T126` and `native-after: T126` (since T126 is marked done), the following slice tests fail:
   - `tests/run/slice/qa_slice_bounds_panic.ax` (Native mode exits with 0 instead of 101)

   - `tests/run/slice/qa_slice_open_ranges.ax` (`AX_TYPE_UNKNOWN_FIELD` on `v1.len`)

   This indicates that T126 was prematurely marked done or is missing functionality.

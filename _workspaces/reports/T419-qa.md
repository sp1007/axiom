   - **Part 1 (Early Return Drop Order)**: Verifies that when an inner async function encounters an error propagated via `?`, all live locals in the outer frame are dropped in strict reverse declaration order (`drop_tag=11`, then `drop_tag=10`), returning `Result.Err(-99)` without leaks.

     2. Inner frame live locals in reverse declaration order (`drop_tag=22`)
     3. Inner frame parameters in reverse declaration order (`drop_tag=21`, `drop_tag=20`)
     4. Outer frame live locals in reverse declaration order (`drop_tag=102`)
     5. Outer frame parameters in reverse declaration order (`drop_tag=101`, `drop_tag=100`)

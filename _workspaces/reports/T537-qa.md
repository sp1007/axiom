### Findings (FAIL)

#### Finding F1 — CallGraph / IPA summary inference proves functions that read/write `MIR_LOCAL_STATIC` or `MIR_LOCAL_TLS` as `EFFECT_PURE` (`PROP_PURE_CALL`)
- **Location**: `compiler/opt/inline/mod.ax:1298-1397` (`cg_body_external_mem_flags`) and `compiler/opt/inline/mod.ax:1444-1504` (`callgraph_update_node_summary`).
- **Expected**: Functions reading or writing a global `MIR_LOCAL_STATIC` (`6u8`) or `MIR_LOCAL_TLS` (`5u8`) place (or mutable `MIR_LOCAL_CONST`) must record `EFFECT_READS_MEM` / `EFFECT_WRITES_MEM` in `EffectCallTable` and must **never** be marked `EFFECT_PURE` (`pure_certainty = CERTAINTY_PROVEN`, which stamps `PROP_PURE_CALL` at `inline/mod.ax:2830` and `ipa/mod.ax:2379`). (`T537-report.md` line 23 explicitly claimed this was implemented, but neither `inline/mod.ax` nor `ipa/mod.ax` checks `MIR_LOCAL_STATIC`/`MIR_LOCAL_TLS` in summary inference.)
- **Actual**: `callgraph_update_node_summary` (`lines 1444-1446`) strips `EFFECT_READS_MEM | EFFECT_WRITES_MEM` from `new_eff.flags` and replaces them with `cg_body_external_mem_flags(mir_p as *const MirBody)`. `cg_body_external_mem_flags` inspects **only** `cg_place_has_deref` / `cg_op_has_deref`. Because direct and field/index-projected accesses to `MIR_LOCAL_STATIC` / `MIR_LOCAL_TLS` (`G = 99`, `G.f = 1`, `let x = G`) have zero `MIR_PROJ_DEREF` projections, `cg_body_external_mem_flags` returns `0u16`. `callgraph_propagate_summaries` therefore assigns `flags = EFFECT_PURE (0u16)` and `pure_certainty = CERTAINTY_PROVEN (0u8)`!
  - Downstream `memopt` (`compiler/opt/memopt/mod.ax:988`: `if (eff & (EFFECT_WRITES_MEM | EFFECT_FFI | EFFECT_UNKNOWN)) == 0u16 { return false; }`) and `loops` (`compiler/opt/loops/mod.ax:2888`) treat non-inlined calls to `set_g()` as non-clobbering, forwarding stale global loads across `set_g()`, while `scalar` (`compiler/opt/scalar/mod.ax:4518, 4555, 4635, 4950, 5530`) deletes void calls `set_g()` as dead `PROP_PURE_CALL`s and CSEs `get_g()` across mutations.
- **Empirical Repro**: Constructing `fn set_g() { G = 99; }` (`_1: MIR_LOCAL_STATIC, const_sym = 42`) and running `callgraph_propagate_summaries` prints:
  `F1_writes_mem=0 F1_pure_cert=0` (`EFFECT_WRITES_MEM` bit is `0`; `pure_certainty == CERTAINTY_PROVEN == 0`).
- **Required Fix**: Update `cg_body_external_mem_flags` in `compiler/opt/inline/mod.ax:1298-1397` so places/operands rooted at `MIR_LOCAL_STATIC`, `MIR_LOCAL_TLS`, or mutable `MIR_LOCAL_CONST` record `EFFECT_WRITES_MEM` on assignments/drops/call destinations/mutable borrows and `EFFECT_READS_MEM` on reads/borrows. (Also check `compiler/opt/lto/mod.ax` if any LTO summary builder inspects MIR locals similarly.)

### Follow-ups (for axiom-architect)
1. **Driver `-O2` does not reach OptIR.** The driver never invokes the OptIR inline/IPA/alias/memopt passes, so F1/F2-class bugs are invisible to every end-to-end `-O2` test. The task that wires OptIR into the driver should rerun `tests/run/static_items` (and the `opt_o2_*` files) with a native `-O2` leg.
2. **`memopt_optimize_mir_body` fails `verify_mir` on `mir_build_fn` output.** The engineer reports a "use of uninitialized local" error for every function, so it is pre-existing. It needs a repro and an owner. Until then, memopt cannot be tested on builder MIR without `memopt_run_pass_with_info`.
3. **Dangling attribute literals.** `session_parse_virtual_file` (`compiler/parser/session.ax`) frees the lexer arena while HIR string literals still point into it. Probes or tools that use this path read dangling attribute literals.
4. **Shared Atomic-type predicate.** `cg_type_contains_atomic` and `al_type_contains_atomic` copy `backend_type_contains_atomic` but drop its name check. One shared predicate keyed like `tc_struct_is_lang_atomic` / `tc_type_is_lang_atomic` would keep typeck, backend placement and the optimizer from drifting apart.
5. **Weak memopt sub-check.** The engineer probe's `PROBE_STATIC_MEMOPT_CALL_CLOBBER` cannot fail today, because memopt does no RLE of whole-local global reads. Make it a sensitivity test once memopt does global RLE.

#### Finding 1 (CRITICAL — Silent Native Miscompilation & Existing Suite Regressions)
- **Location**: `compiler/target/x64/isel.ax:2101-2113` (`isel_vreg_const`) and `compiler/target/x64/isel.ax:3687-3705` (`isel_opt_pass3_aliases`), interacting with `MIR_RVALUE_CAST` lowering in `compiler/lir/builder.ax:1174-1176` and `compiler/lir/builder.ax:1448-1451`.
- **Violated Spec / Requirement**: `SPEC-77 AXS-MCOPT-002` (bit-exact semantic preservation), `AXS-MCOPT-003` (two's-complement width semantics), `REQ-OPT-205`, and `T628` Acceptance Criteria #7 & #8 (`0` regressions across existing suites; `interp` vs `native` differential equivalence).
- **Expected vs Actual**:
  - **Expected**: Narrowing or sign-changing integer casts (`x as u8`, `x as i8`, `x as u16`, `x as u32`, etc.) on constant-backed locals must truncate to the target width and zero-/sign-extend according to the cast target type (`TypeId`), matching `--interp`. Existing tests `tests/run/intrinsics/ops_table.ax` and `tests/run/parity/intrinsics/qa_intrinsics_ptr_edges.ax` must exit `0` in `native` and `native-O1`.
  - **Actual**: In `compiler/lir/builder.ax:1174-1176` & `1448-1451`, `MIR_RVALUE_CAST` lowers `x` via `LIR_INST_LOAD` (`(*inst).ty = typeof(x)`, e.g., `i64` or `i8`) and mutates only the destination vreg's type (`(*vp).ty = target_ty_v`, e.g., `u8` or `u32`), relying on stack store/load width truncation/extension in baseline isel. In `x64_isel_opt_in_arena`, `isel_opt_pass3_aliases` (`isel.ax:3698-3702`) records `slot_const_val[slot_x] = -1i64` (`0xFFFFFFFFFFFFFFFF`), and when lowering the cast's `LIR_INST_LOAD`, `isel_vreg_const` (`isel.ax:2101-2111`) returns `slot_const_val[slot_x]` raw (`-1i64`) without truncating or sign-/zero-extending to `(*inst).ty` or `isel_vreg_ty(lir, rv)`. `isel_opt_pass3_aliases` then stores the untruncated 64-bit value into `slot_const_val[slot_y]`, corrupting every downstream read of `y`:
    - `(-300i64 as u8) as i64` evaluates to `-300` instead of `212`.
    - `((-1i64) as u32) % 7u32` computes `u64.MAX % 7 == 0` instead of `u32.MAX % 7 == 3`.
    - `((-1i64) as u32) >> 1u32` evaluates to `4294967295u32` instead of `2147483647u32`.
    - Sub-64-bit bit-manipulation intrinsics (`count_ones_i8(-1i8)`, `leading_zeros_i8(-1i8)`, `rotate_right_i8(-128i8, 1u32)`, etc.) cast signed negative constants to unsigned sub-word types (`u8`/`u16`) before shifting/counting, causing `tests/run/intrinsics/ops_table.ax` (`exit 1`) and `tests/run/parity/intrinsics/qa_intrinsics_ptr_edges.ax` (`exit 19`) to fail natively.
- **Minimal Reproducer (`repro_cast_all4.ax`)**:

      let x: i64 = -300i64;
      let y: u8 = x as u8;
      y as i64
  }

  fn cast_u8_to_i8() -> i64 {
      let b: u8 = 200u8;

  }

      y % 7u32
  }

      let x: i64 = -1i64;
      let y: u32 = x as u32;
      y >> 1u32
  }

  fn main() -> i32 {
      let mut mask: i32 = 0;
      if cast_neg_to_u8() != 212i64 { mask = mask | 1; }
      if cast_u8_to_i8() != -56i64 { mask = mask | 2; }
      if cast_neg_u32_mod7() != 3u32 { mask = mask | 4; }

#### Finding 3 (MAJOR — Unsound `^ 1` Condition Inversion on Non-Boolean Integer `LIR_TERM_SWITCH`)
- **Location**: `compiler/target/x64/isel.ax:3193-3201` (`isel_emit_cond_flags_for_branch`), called from `isel_try_if_convert_diamond` (`compiler/target/x64/isel.ax:3254-3256`, `3332`) and `isel_opt_lower_terminator` (`compiler/target/x64/isel.ax:3771-3777`).
- **Violated Spec / Requirement**: `SPEC-77 AXS-MCOPT-002` (semantic equivalence across all inputs), `AXS-MCOPT-013`, `REQ-OPT-207`.
- **Expected vs Actual**:
  - **Expected**: Rewriting `(lhs ^ 1) != 0` into `!(lhs != 0)` (`lhs == 0` via `x64_cc_invert`) is valid **only** when `lhs` has type `TY_BOOL` (values restricted to `{0, 1}`). For any integer type wider than `bool` (`i8..i64`, `u8..u64`), `(lhs ^ 1) != 0` is `lhs != 1`, which is `true` for `lhs = 2` (`(2 ^ 1) == 3 != 0`), whereas `lhs == 0` is `false`.
  - **Actual**: Both `isel_try_if_convert_diamond` (`isel.ax:3254-3256`) and `isel_opt_lower_terminator` (`isel.ax:3771-3777`) invoke `isel_emit_cond_flags_for_branch` on `LIR_TERM_SWITCH` with `count == 1` and `t_val == 0u64` without requiring `cond_v` to be `TY_BOOL` (contrast lines `3257-3262`, where `t_val == 1u64` explicitly checks `(*ct).kind == TY_BOOL`). Inside `isel_emit_cond_flags_for_branch` (`isel.ax:3193-3201`), `k == LIR_INST_BIT_XOR` with `rhs == 1` strips the `^ 1` and inverts `cc` without checking `TY_BOOL` on `rc` / `lhs`.
- **Repro**: Calling `x64_isel_opt_in_arena` on a `LirBody` containing `v2 = xor v1, 1` (`i64`) feeding `switch v2 [0: bb_else, otherwise: bb_then]` emits `test r_v1, r_v1` + `cmovcc CC_E` (or `jcc CC_E`), selecting `bb_else` instead of `bb_then` for every `v1 >= 2` (and every negative `v1`).

#### Finding 4 (MODERATE — Unsound `EFLAGS` Liveness in `x64_flags_are_dead_after` and `peep_cmp_zero_can_use_test`)
- **Location**: `compiler/target/x64/frame.ax:2806-2839` (`x64_flags_are_dead_after`) and `compiler/target/x64/frame.ax:3022-3055` (`peep_cmp_zero_can_use_test`).
- **Violated Spec / Requirement**: `SPEC-77 AXS-MCOPT-021` §1 & §2 (`spec/SPEC-77-regalloc-machine-opt.md:350-366`), `REQ-OPT-033`.
- **Expected vs Actual**:
  - **Expected**:
    1. Per `SPEC-77 AXS-MCOPT-021` §2: *"If the scan reaches an instruction in `FLAGS_USE` (`jcc`, `setcc`, `cmovcc`, `assert`) or reaches the end of `mbb` without encountering a `FLAGS_DEF` or `FLAGS_KILL` instruction, `EFLAGS` are **conservatively live** (`false`)."*
    2. Per `SPEC-77 AXS-MCOPT-021` §1 and Intel x86-64 SDM (`SAL/SAR/SHL/SHR`), shifts overwrite `EFLAGS` **only** when the masked shift count `(count & 63) != 0`. Variable-count shifts (`op1.kind == X64_OP_REG`, i.e., `shl/shr/sar reg, cl`) leave `EFLAGS` unmodified at runtime whenever `(cl & 63) == 0`, so they cannot prove prior `EFLAGS` dead.
  - **Actual**:
    1. `x64_flags_are_dead_after` returns `true` on `opc == X64_MI_JMP` (`frame.ax:2833-2835`) and at end-of-block `(curr as usize) == 0` (`frame.ax:2838`), and `peep_cmp_zero_can_use_test` likewise returns `true` at `(curr as usize) == 0` (`frame.ax:3054`) and continues past `JMP`/`RET`. Because `x64_peephole_opt_in_arena` (`frame.ax:3481-3491`) runs `peep_opt_cfg` (which deletes fallthrough `X64_MI_JMP` terminators at the end of `mbb`) and then re-runs `peep_opt_basic_block` (`frame.ax:3487`), fallthrough blocks end with `curr == 0`; an `X64_MI_MOV reg, 0` at the end of a fallthrough block falsely reports `x64_flags_are_dead_after == true` and rewrites to `xor reg, reg`, clobbering `EFLAGS` across the fallthrough boundary.
    2. Both `x64_flags_are_dead_after` (`frame.ax:2818-2825`) and `peep_cmp_zero_can_use_test` (`frame.ax:3038-3045`) only guard `op1.kind == X64_OP_IMM && (op1.imm & 63i64) == 0i64`, treating variable shifts (`op1.kind == X64_OP_REG`) as unconditionally killing `EFLAGS`.
- **Repro**: Construct a 2-block `X64MIBody` (or unit test via `x64_peephole_opt_in_arena`) where `bb0` executes `cmp rcx, rdx; mov rax, 0; jmp 1` and `bb1` starts with `cmovcc CC_L, rax, r8; ret`: `peep_opt_cfg` removes the fallthrough `jmp 1`, and the second `peep_opt_basic_block` pass rewrites `mov rax, 0` into `xor rax, rax`, destroying the `cmp rcx, rdx` flags before `cmovcc` in `bb1`. Likewise, `cmp rcx, rdx; mov rax, 0; shl r8, cl; cmovcc CC_L, rax, r9` rewrites `mov rax, 0` to `xor rax, rax`, corrupting `CC_L` whenever `cl == 0`.

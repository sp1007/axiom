# T445a — Drop pattern bindings at the end of their arm

## Goal
ADR-0047 / SPEC-12 AXS-DROP-009: each `match` arm is a drop scope; `if let` bindings die at the end of the then-block,
`while let` bindings at the end of each iteration. Today a by-value arm binding (e.g. `E.Payload(_g) => ..` with a `Drop`
payload, or `FiberState.Yielded(_g)`) is dropped at the end of the enclosing block or function
(`_workspaces/reports/T444b-report.md` F2: `got 1 2\nafter-two\ndrop 2\ndrop 1`; `_workspaces/reports/T445-report.md`
deviation 2; T423 QA). Interp, native and native-O1 agree, so the fix is in MIR construction (scope/drop elaboration).

## Scope
- In the MIR builder (and the ownership/drop-flag pass if needed), open a drop scope per arm / if-let then-block / while-let
  body for the pattern bindings, and emit their drops at the scope end and on every early exit (`return`, `break`,
  `continue`, `?`), reverse pattern order, drop-flag aware (a binding moved out in the arm is not dropped). Scrutinee rule of
  AXS-DROP-009 (place: remaining parts stay in the place, partial-move flags; temporary: remaining parts dropped at the end of
  the statement). `let` bindings unchanged.
- Update every test that pinned the old drop point, starting with `tests/std/async/structured/src/resource_governor_limits.axsrc`
  section 4: check the lease results without moving them (e.g. a helper taking `view<Result<Lease, E>>`), keep the intent
  (leases alive until the block ends, usage back to 0 after it), regenerate with `python tests/std/async/structured/gen_tests.py`
  (`--check` passes). Any other test the gate reports as depending on the old point is corrected to the new rule (list them in
  the report); `tests/std/fiber` included (regenerate with its `gen_tests.py` if an `.axsrc` changes — only if that file is free;
  otherwise report it).
- Tests `tests/run/drop_arm_scope/*.ax` (`modes: interp native`, exact stdout, each drop prints an id): binding dropped before
  the statement after the `match`; two bindings in one pattern (reverse order); nested pattern and `@` binding; binding moved out
  in the arm (no drop); early `return`/`break`/`continue` from an arm; `?` in an arm; `if let` and `while let` (per iteration);
  scrutinee place with one field bound and one not (unbound part dropped with the place at block end); temporary scrutinee
  (remaining parts dropped at the end of the statement); guard that fails (no move, no drop in that arm); `let` pattern binding
  still lives to the end of the block.
- Keep the stage-2/stage-3 fixed point; selfhost bundles are regenerated by `taskctl snapshot`/`accept` (do not edit or list them).

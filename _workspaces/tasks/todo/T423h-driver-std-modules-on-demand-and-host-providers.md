# T423h — std modules on demand; host providers in native builds

## Goal
Implement ADR-0048. Today (triage-1122, reproduced with the current stage-2 compiler):
- `use std.core.host.exit` + `exit(3)`: interp exits 3, `build` fails with `AX_LINK_UNDEFINED_SYMBOL: __ax_host_exit`
  (also `args_count` → `__ax_host_args_count`). ADR-0002 §3 requires the compiler to add the provider module.
  (`_workspaces/reports/T423b-qa.md` follow-up 3.)
- `use std.core.mem.swap`, `use std.core.cmp.min`, `use std.process.exit` report `AX_NAME_UNRESOLVED_IMPORT`: only the
  prelude, option/result, `core/host.ax`, the `future` modules and `std.sync.atomic` are ever loaded.

## Scope
- `compiler/driver/pipeline.ax`: std module index (header scan of `<std-root>/**/*.ax`, sorted, deterministic), on-demand
  transitive loading for `use std.…` paths (longest module prefix), "program-provided module wins" (bundles that declare
  `module std.x` inline, user files, and the existing special cases), duplicate-header error. Fold the existing special cases
  (`pipe_append_std_extra_mod_if_needed`, future/atomic) into the general mechanism where that is behaviour-preserving.
- Native builds: each used `std.core.host.X` adds the `std.sys.windows.*` module that defines `pub fn __ax_host_X` (found
  through the index). Interp (`run --interp`, `check`) does not add providers.
- `--dep-file`: loaded std files plus the scanned directories (`<dir>/ dir`), per ADR-0041 §4.
- Remove the workaround `__ax_host_*` definitions from `tests/run/host/**` and check every test there in all its modes.
- Tests `tests/modules/std_on_demand/`: `use std.core.mem.swap` (run, three modes), a transitive std import, an item import
  vs a module import, `std.asyn.*` (header ≠ path), a bundle-style inline `module std.x` that must win, an unknown
  `use std.nope` (`AX_NAME_UNRESOLVED_IMPORT` unchanged), a `--dep-file` golden showing the loaded std files; native
  `exit(3)` / `args_count()` with no workaround definition (exit code and stdout checked).
- Compile time: measure `tests/run` total time before/after (report the numbers); the index scan must not re-read files
  already loaded.
- Keep the stage-2/stage-3 fixed point (the compiler itself does not depend on on-demand std loading); selfhost bundles are
  regenerated by `taskctl snapshot`/`accept` (do not edit or list them).

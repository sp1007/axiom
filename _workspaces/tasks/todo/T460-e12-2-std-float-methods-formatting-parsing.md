# T460 — E12.2 — Float formatting, exact parsing & std.core.float methods

## Goal
Implement `std/core/float.ax` (`f32`/`f64` constants, classification, `total_cmp`, bit conversions) and `std/text/fmt/float.ax` (shortest round-trip decimal formatting, fixed/scientific formatting, and exact decimal parsing).

## Scope
- Create `std/core/float.ax` providing `f32` and `f64` associated constants (`f16` members are added by `T480`) (`INFINITY`, `NEG_INFINITY`, `NAN`, `EPSILON`, `MIN`, `MAX`, `MIN_POSITIVE`, `MANTISSA_DIGITS`, `MIN_EXP`, `MAX_EXP`, `RADIX`), `FpCategory`, classification predicates (`is_nan`, `is_infinite`, `is_finite`, `is_normal`, `is_subnormal`, `is_sign_positive`, `is_sign_negative`, `classify`), IEEE total ordering (`total_cmp`), `clamp`, `to_bits`, `from_bits`, `to_degrees`, `to_radians`, `next_up`, and `next_down`.
- Implement the derived operations of ADR-0049 §4 in `std/core/float.ax` as pure Axiom over the T458a intrinsics: `floor`, `ceil`, `trunc`, `round`, `round_ties_even`, `fract`, `min`, `max`, `mul_add` (exact integer soft-float, single rounding for every input including subnormal and overflow ranges), plus the method wrappers `sqrt`, `abs`, `copysign` (AXS-FLT-015, 016, 026, 062). They must not be `@intrinsic`.
- Create `std/text/fmt/float.ax` and wire it into `std/text/fmt/format.ax`: shortest round-trip decimal output (`parse(format(x)) == x` bit-for-bit for all finite `f32`/`f64`), fixed-precision (`format_f64_fixed(x, decimals)`), scientific notation (`format_f64_exp`), and canonical formatting of `NaN`, `inf`, `-inf`, and `-0.0`.
- Implement exact round-to-nearest-even float parsing (`parse_f32`, `parse_f64` -> `Result<f32/f64, ParseFloatError>`) in `std/text/fmt/float.ax`.

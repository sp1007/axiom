# T498g — Generic raw-memory intrinsics with an array `T`

## Goal
Silent wrong result in both execution modes (`_workspaces/reports/T498c-qa.md` FU-QA-T498c-2, reproduced by the architect in
triage-1122 with the current stage-2 compiler, interp and native identical):

```
@intrinsic pub unsafe fn address_of_mut<T>(val: T) -> *mut T { 0 as *mut T }
@intrinsic pub unsafe fn ptr_copy_nonoverlapping<T>(src: *const T, dst: *mut T, count: usize) {}
@intrinsic pub fn size_of<T>() -> usize { 0 }
unsafe fn swap2<T>(a: mut_view<T>, b: mut_view<T>) {      // body of std/core/mem.ax `swap`
    let pa = address_of_mut(*a)
    let pb = address_of_mut(*b)
    let mut tmp: [1]T = [*a]
    let ptmp = address_of_mut(tmp[0])
    ptr_copy_nonoverlapping(pa as *const T, ptmp, 1)
    ptr_copy_nonoverlapping(pb as *const T, pa, 1)
    ptr_copy_nonoverlapping(ptmp as *const T, pb, 1)
}
// p: [4]u32 = [1,2,3,4], q = [10,20,30,40]; swap2(mut_view(p), mut_view(q))
// prints size_of<[4]u32>() = 16, then p[0]=10 p[1]=2 p[3]=4 q[0]=1 q[3]=40   (expected 10 20 40 / 1 40)
```

Only 4 bytes (one `u32`) move per `ptr_copy_nonoverlapping<[4]u32>(.., 1)`. Likely cause: when `T` is an array, the element
size of the intrinsic is taken from the array element (or `address_of_mut(*a)` decays to an element pointer, or the `[1]T`
temporary is typed from the wrong type). Find the root cause; do not special-case `swap`.

## Scope
- Fix the root cause so `ptr_copy`, `ptr_copy_nonoverlapping`, `ptr_write_bytes`, `ptr_add`/`ptr_sub` and `address_of(_mut)` use
  `size_of<T>()` of the substituted `T` for arrays, nested arrays, arrays of structs, tuples and structs containing arrays, in
  the interp and in native `-O0`/`-O1`.
- Tests `tests/run/mem_generic_array/` (three modes, exact `stdout:`): the repro; `[N]T` for `T` in `u8`, `u32`, `u64`, a
  struct, `[2][3]u16`; `count` 0/1/3 over an array of arrays; `ptr_write_bytes` over an array `T`; `replace` on an array.
  Copy the generic bodies into the test (std module loading on demand is T423h).
- Keep the stage-2/stage-3 fixed point; selfhost bundles are regenerated by `taskctl snapshot`/`accept` (do not edit or list them).

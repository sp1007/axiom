# T423i — Provide linkable `std.sys.windows.*` host-provider archive in `gnu_ld_run_oracle.py` and private-fn `SYM_LOCAL` in multi-file `--emit=obj` (`fullrun-4` R2)

## Goal
Resolve `fullrun-4` regression R2 (`link/dll/gnu_ld_run.test`: 10/1076 `tests/run/host/{fs,heap,io}/*.ax` tests fail GNU `ld` with undefined `__ax_host_*` references) introduced when `T423h` (`4f2daaf0`, ADR-0048) removed inline `fn __ax_host_*` workarounds from `tests/run/host/**` while keeping relocatable `--emit=obj` / `--kind lib` outputs free of embedded host providers.

Repro before fix (in an isolated snapshot):
```
python tests/link/dll/gnu_ld_run_oracle.py build/axiomc2.exe build/_tmp_gnu_ld .
```

## Scope
- Keep `T423h`'s `pipe_wants_host_providers` rule (`--emit=obj` and `--kind lib` leave `__ax_host_*` undefined for final link) and keep `axiom_rt.obj` (`build --rt-obj`) byte-for-byte untouched (`qa_t431_tls_and_std_reachability_bounds.test` pins its exact 48-byte `.rdata` layout and 4 TLS relocations).
- In `compiler/driver/pipeline.ax` (`driver_emit_objmodel_filtered_ex`, symbol binding around line 7726):
  - When emitting a per-module relocatable `.obj` in a multi-file compilation (`for_obj && filter_fid_v != 0u32`), give module-private functions (`vis.kind == 0u8`, `!has_export`, `!pipe_item_has_entry_attr(...)`, `!pipe_sv_is_main(view(fname_sv))`, `!pipe_sv_has_dollar(view(fname_sv))`) `SYM_LOCAL` (`IMAGE_SYM_CLASS_STATIC`) binding just like `for_lib`, so non-`pub` helpers in separate modules (e.g. `fn_entry_to_addr`, `fn_exit_to_addr`, `addr_to_fn_exit` in `std/sys/windows/fiber.ax` and `std/sys/windows/thread.ax`) never collide at link time.
  - Keep single-file `--emit=obj` (`filter_fid_v == 0u32`) 100% unchanged so `axiomc_e2e.test`, `qa_obj_link_driver_diff.ax`, and `qa_t442_obj_link_driver_bounds.test` remain byte-for-byte identical.
- In `tests/link/dll/gnu_ld_run_oracle.py` (`SPEC-26 AXS-WLIB-032 (2)`):
  - Once at startup alongside `axiom_rt.obj`, compile the `std/sys/windows/*.ax` host provider modules into relocatable `.obj` files via `{compiler} build --std-root <std> --emit=obj`: `heap.ax`, `io.ax`, `fs.ax`, `process.ax`, `time.ax` individually, plus `thread.ax` (with `fiber.ax` as second positional `.ax` file) and `fiber.ax` (with `thread.ax` as second positional `.ax` file) so `fiber.obj` references `thread.obj`'s `__ax_host_thread_current_id` externally without duplicating `thread.ax` definitions.
  - Validate every provider `.obj` with `inspect_coff_external_symbols` (confirming valid COFF headers and zero leaked `<dll>$<fn>` or `__IAT_*` symbols), and pack all 7 provider `.obj` files into a deterministic COFF archive `axiom_host_rt.lib` via `{compiler} build --kind lib -o <path> <objs...>`.
  - Pass `str(axiom_host_rt_lib)` on `ld_cmd` in `verify_test` **after** `str(prog_obj)` and `str(rt_obj_1)` and **before** `*mingw_L_args` / `-lkernel32 ...` so tests not using `host.*` extract 0 members, legacy tests defining inline `fn __ax_host_*` keep their own definitions without duplicate symbols, and all 10 `tests/run/host/{fs,heap,io}/*.ax` tests link and execute identically to `self.exe`.
  - Extend section 2 (`gcc -nostdlib` smoke) to also cross-link and run a smoke program calling `std.core.host.heap_alloc`, `std.core.host.thread_yield`, and `std.core.host.fiber_destroy` together against `axiom_rt.obj` + `axiom_host_rt.lib` (`-lkernel32 -lsynchronization` when `has_sync_lib`) to lock in collision-free co-linking of `thread.obj` and `fiber.obj`.
- Keep the stage-2/stage-3 fixed point; selfhost bundles are regenerated by `taskctl snapshot`/`accept` (never edit or list generated bundles).

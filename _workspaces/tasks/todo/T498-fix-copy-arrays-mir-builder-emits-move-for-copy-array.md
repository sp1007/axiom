# T498 — `[N]T` is Copy iff `T` is Copy (ADR-0044 §3)

## Goal
Passing, assigning or returning a fixed array whose element type is `Copy` copies it; the source stays usable.
Observed (T455, FU-T455-ARRCOPY): `fn take(a: [2]u8) -> u8` called twice with the same array reports `AX_VERIFY_USE_AFTER_MOVE`
on the second call, although `type_is_copy` (`compiler/types/types.ax`) already answers "array Copy iff element Copy".
Root cause located by the architect: `mb_operand_from_place` in `compiler/mir/builder.ax` sets `is_cp = false` for every `TY_ARRAY`
(and `TY_STR`) and emits `MIR_OP_MOVE`, ignoring `type_is_copy`.

## Scope
- `mb_operand_from_place`: use `mb_type_is_copy` for `TY_ARRAY` (keep `TY_STR` non-Copy); an array of a non-Copy element type still
  moves. Check every other builder site that special-cases arrays (aggregate construction, `let b = a`, return, call arguments,
  by-value `self`, array of arrays `[N][M]T`, array in a tuple/struct field) and make them agree with `type_is_copy`.
- Check the consumers of `MIR_OP_COPY` with an aggregate operand: MIR interpreter, `compiler/own` / `own_mir_verify`, optimizer passes
  (`compiler/opt`), LIR lowering and the x86-64 backend (large arrays: memcpy-style copy; `[0]T` and `[1]T` edge cases; a 4096-element
  array must not overflow the stack probe, ADR-0003). Fix what is wrong in the owning module only if a failing test proves it; report
  anything bigger as a follow-up.
- Tests: remove the `xfail` line of `tests/run/numeric/mixed_int_matrix/array_copy.ax`; add `tests/run/array_copy/*.ax`
  (copy into two bindings, call argument twice, return of a copy, `[2][3]u8`, array field of a struct, a 1 KiB array, mutation of the copy does not change the
  source, interp/native/native-O1 with exact `// stdout:`) and `tests/ui/array_copy/*.ax` (array of a non-Copy element used twice still reports
  `AX_VERIFY_USE_AFTER_MOVE`).
- Keep the stage-2/stage-3 fixed point (the compiler's own sources use arrays); selfhost bundles are regenerated by `taskctl snapshot`/`accept`
  (do not edit or list them).

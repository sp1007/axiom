# T499 — unary `~` is a tree node of a widening integer tree (ADR-0044 §2)

## Goal
In `let t: i64 = ~b8 + s64` with `b8: u8 = 255`, `s64: i64 = 1000` the result is `744` (`~255i64 == -256`): `~` is evaluated in the
tree context type after widening its operand, like every binary operator and unary `-` (SPEC-40 AXS-INT-052 rule 4, ADR-0044 §2).
Observed (T455, FU-T455-TILDE): `check_unary_in_arith` in `compiler/types/typeck.ax` computes `~b8` in `u8` (= 0) and only then widens,
giving `1000`. A `~x` outside a widening tree keeps `x`'s type (`let r: u8 = ~b8` is `0`; AXS-INT-050.2, 052.3).

## Scope
- `compiler/types/typeck.ax` `check_unary_in_arith` (unary `~` branch): when the tree context `ctx_ty` is a wider integer type than the operand's
  concrete type, type the operand in `ctx_ty` (widening cast of the operand, zero-extend unsigned / sign-extend signed) before applying `~`;
  the existing `-` branch is the model (unsigned operand of `-` stays `AX_TYPE_NEG_UNSIGNED`). The MIR builder already inserts promotion casts for
  typed-in-context operands; check that `~` of a promoted operand lowers to `Cast(IntToInt, b8, i64)` followed by the `Not` in `i64`
  (`axiomc inspect --emit=mir`), homogeneous operands (INV-INT-003).
- Compile-time evaluation (`compiler/interp` const path) and the oracle must agree with native for these trees (`const X: i64 = ~255u8 + 1000;`
  is tree-typed too if it is an arithmetic tree with an expected type).
- Tests: remove the `xfail` line of `tests/run/numeric/mixed_int_matrix/tilde_widening.ax`; add `tests/run/numeric/tilde_tree/*.ax` (every
  signed/unsigned narrow leaf x contexts i16/i32/i64/i128/isize/usize with expectations computed with exact Python integers, a `--emit=mir`
  check of the cast, interp/native/native-O1 with exact `// stdout:`) and `tests/ui/tilde_tree/*.ax` (`-b8` in a tree still `AX_TYPE_NEG_UNSIGNED`;
  `let f: i32 = ~x` with `x: u8` still `AX_TYPE_MISMATCH`).
- Search the compiler's own sources for `~` applied to a narrow unsigned operand inside a wider tree (stage-2 and stage-3 must still be a fixed point;
  a changed meaning in the compiler's own code is a self-hosting risk — list every hit in the report).
- Selfhost bundles are regenerated by `taskctl snapshot`/`accept` (do not edit or list them).

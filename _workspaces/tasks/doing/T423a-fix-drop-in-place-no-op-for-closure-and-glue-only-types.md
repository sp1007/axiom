# T423a — `drop_in_place<T>` runs the full drop glue

## Goal
`_workspaces/reports/T423-qa.md` F1: for a closure `F` capturing a `Guard` with `impl Drop`, `needs_drop<F>()` is true but
`drop_in_place<F>(p)` prints nothing (interp and native agree), while `let _moved: F = *p;` drops the capture. Cause
(`compiler/mir/builder.ax` `mb_scan_or_rewrite_calls`): the builtin call is rewritten into a call of the monomorphized
`Drop` impl only when `T` itself has a `Drop` impl (`mb_instantiate_drop_for_ty`); for every other type that needs drop the
builtin stays and does nothing. SPEC-12 AXS-DROP-005 requires recursive drop glue. Owned resources reached only through raw
pointers (boxed closures in `std.fiber`, `std.thread`, containers holding tuples/closures) silently leak.

## Scope
- Make `drop_in_place<T>(p: *mut T)` run exactly what a scope-end `DROP` of a `T` place runs, for every `T` with
  `needs_drop<T>()`: own `Drop` impl first then fields (AXS-DROP-005, SPEC-54 rule on composite drop order), closures
  (captured values in capture order as for a scope drop of the closure), tuples, arrays `[N]T`, structs/enums without their
  own `Drop` but with droppable fields, nested combinations. A `T` without drop needs stays a no-op. Suggested shape:
  lower the builtin to a `MIR_TERM_DROP` of the place `(*p)` (the drop elaboration already handles every kind), or a
  synthesized per-type glue function; the same MIR serves interp and native.
- Keep `drop_in_place` on a struct with its own `Drop` impl exactly as today (no double drop of fields that the impl
  already handles — follow the existing scope-drop behaviour).
- Tests `tests/run/drop_in_place_glue/*.ax` (`modes: interp native`, exact `// stdout:`, each drop prints an id): closure with
  1 and 3 captured `Drop` values (order checked), closure capturing a `Box`-like owner, tuple `(Guard, i64, Guard)`,
  `[2]Guard`, struct without `Drop` holding two `Guard` fields, enum variant holding a `Guard`, struct with own `Drop` holding a
  `Guard` field (impl first, then field), a type with no drop needs (prints nothing), the value reached through a heap cell
  (`heap_alloc` + raw store + `drop_in_place` + `heap_free`) for closures and tuples; generic wrapper `fn kill<T>(p: *mut T)`
  instantiated for each of the above.
- Keep the stage-2/stage-3 fixed point; selfhost bundles are regenerated by `taskctl snapshot`/`accept` (do not edit or list
  them).

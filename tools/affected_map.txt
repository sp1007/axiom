# compiler module directory -> test targets for `axtest.py --affected` (T437a rule 2c).
#
# One row per directory under compiler/: `compiler/<mod> -> tests/<path> [tests/<path> ...]`. A target is a
# directory (every test under it) or one test file. A changed file anywhere under compiler/<mod>/ selects
# every target of the row; the selfhost bundles that embed the changed module are added by the bundle grep,
# independently of this table. `python tools/axtest_affected.py --check-map` validates the table (every
# module directory has a row, every target exists); `--affected` refuses to run on an invalid table, so a
# task that adds a compiler module directory adds its row in the same change.
# Targets must be tracked at HEAD: a target that does not exist or is untracked (another task's in-progress
# work) is printed as MAP-NOTE and skipped, never a failure. TODO(architect/T437b): add
# tests/run/int128_interp to the compiler/interp row once T452 has landed it.
# Targets name the groups that exercise the module most directly; every compiled test can observe any
# compiler change, which is what the smoke set and the periodic full run cover.
